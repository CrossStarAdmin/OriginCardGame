# カードフレーム

カード枠のテンプレート。`イラスト/` の生成画像とこの枠を合成して完成カードを作る。

種類ごとにディレクトリを分ける。**種類によって持つ情報が違う**（スペルは攻撃力とHPを持たず、リーダーはコストと攻撃力を持たない）。

```
カードフレーム/
  frame.json     … 差し込み位置の実測値
  キャラクター/   … キャラクターカード用（1060x1484）
  スペル/         … スペルカード用（1061x1482）
  リーダー/       … リーダー用（1061x1483）
  tools/         … 枠を加工するスクリプト
  fonts/         … 合成に使うフォント（SIL Open Font License）
```

## フォント

`frame.json` の `fontFiles` に書いたファイルを `fonts/` から読む。PCにインストールしなくてよい。

| 用途 | キー | フォント |
|---|---|---|
| カード名・スキル名 | `fonts.name` | 解星 特ミン ExtraBold |
| コスト・攻撃力・HP | `fonts.stat` | 解星 特ミン ExtraBold |
| 下段の種類・種族タグ、「パワースキル」「リーダー」の見出し | `fonts.label` | Zen Old Mincho Black |
| 効果テキスト、リーダーのスキル効果文 | `fonts.text` | M PLUS 1p Bold |

効果テキストは絵の上の半透明の板に小さく載るので、明朝だと細い横線が埋もれて読めない。ゴシックにしている。

`family` は GDI+ が認識するファミリー名で書く。ExtraBold のファイルは `Kaisei Tokumin ExtraBold` という別ファミリーの Regular として、Bold のファイルは元のファミリーの Bold として登録される。

## パネル下段

キャラクターとスペルの名前の下には種族タグを出す。タグが無いとき、スペルは「スペル」と出し、キャラクターは空欄にする。

ファイル名は**クラスの英名**で揃える。中央のアート窓は透過。

| クラス | リーダー | 枠の色 | キャラクター | スペル | リーダー |
|---|---|---|---|---|---|
| ウォーリア | ガイル・シュリ | 赤 | `Warrior.png` | `Warrior.png` | `Warrior.png` |
| ウィザード | リーゼ・エルナ | 紫 | `Wizard.png` | `Wizard.png` | `Wizard.png` |
| プリースト | アルベル | 金 | `Priest.png` | `Priest.png` | `Priest.png` |
| デーモン | ヴァルカス・ヴェイン | 黒 | `Demon.png` | `Demon.png` | `Demon.png` |

**スペルの `Priest.png` と `Demon.png` は青の枠から色替えして作った。** 手順は下の「色替え」を参照。
`Demon.png` の数値は `--hue 216 --sat 1.0136 --light 0.2689`（`キャラクター/予備_青.png` と旧 `魔剣士.png` の対応画素51853点の中央値）。

リーダー枠の名前帯とスキル欄は全クラス共通の紙色で、クラスの色は外周の帯だけに出る。文字は濃い茶色で載せる。

## イラストの嵌め方

イラストは4:5（0.80）で生成している。アート窓の縦横比は
0.84（キャラクター）／0.82（スペル）／**0.93（リーダー）**。

キャラクターとスペルは幅を窓に合わせて拡縮し、下端を数%切れば収まる。
**リーダーだけは窓が正方形に近い。** 4:5の絵を幅に合わせると下端が2割ほど切れるので、
リーダーの絵は上寄せの構図で生成しておく必要がある。

## 色替え

`tools/recolor.js` は枠の色帯だけを別の色相に置き換える。コスト宝石は全クラス共通なので、
塗りつぶし判定で見つけて必ず保護する。

```bash
node カードフレーム/tools/recolor.js 入力.png 出力.png
```

既定値は**青 → 金**。変換の数値（色相47.61° / 彩度x0.7736 / 明度x1.3444）は、
`キャラクター/予備_青.png`（青）と `キャラクター/Priest.png`（金）が同じ絵の色違いであることを利用し、
色帯の対応画素8761点の中央値から求めた。**他の色に変えるときは同じ手順で数値を出し直す。**

| オプション | 既定 | 意味 |
|---|---|---|
| `--from <低,高>` | `190,255` | 置き換える元の色相の範囲（度） |
| `--hue <度>` | `47.61` | 置き換え後の色相 |
| `--sat <倍率>` | `0.7736` | 彩度の倍率 |
| `--light <倍率>` | `1.3444` | 明度の倍率 |

## 合成に使える情報

合成する対象は `イラスト/<デッキ名>/<カード名>.json` があるカード。
コスト・攻撃力・HP・種族タグ・効果テキストは、合成のたびに `デッキ/<デッキ名>/カード一覧/*.md` から読む（書式は `システム/デッキ読み込み/decks.js` と同じ）。
`.json` の `card` は取り込んだ時点の写しなので、効果を書き換えると古くなる。md にカード名が無いと失敗する。

## フレーバーテキスト

カードmdに `## フレーバー` を書くと、効果テキストの板の下端に色を変えて載る。1行が1行として出る。書かなければ何も出ない。リーダーには出ない。

| キー（`effectBox`） | 意味 |
|---|---|
| `flavorSize` | 文字の大きさ。板の高さの半分を超えるときは小さくする |
| `flavorColor` | 文字の色 |
| `flavorGap` | 効果テキストとの間隔。真ん中に飾り線を引く |
| `flavorRuleColor` | 飾り線の色 |
| `flavorPadBottom` | 板の下端からフレーバーまでの余白。キャラクター枠は y1138 から攻撃力の丸の飾りが重なるので、文字がそこへ届かない値にする |
| `flavorGrowMax` | 板を上へ伸ばせる最大の高さ |

効果テキストが元の大きさで収まらないときは、板を上へ伸ばす。伸ばしきっても収まらなければ効果テキストを小さくする。

## キーワードの色

効果テキストの板では、`frame.json` の `keywords.categories` に書いた語を種類ごとの色で描く。リーダーのスキル欄には付けない。

| 種類 | 色 | 語 |
|---|---|---|
| 能力 | 金 `#FFD166` | 突進、勇気、守護、必殺、ブースト など |
| 強化 | 橙 `#FFA066` | 自由強化、強化 |
| 誘発 | 水色 `#7FD4FF` | 召喚時、死亡時、ターン終了時 など |
| 状態 | 緑 `#8EE59B` | 解放状態、不屈状態、魔力解放状態、癒し状態 など |

- md で「」に囲まれていても、色を付ける語は「」を外して描く。md の文面はそのまま
- 長い語から当てる。「自由強化」は「強化」より、「魔力解放状態」は「解放状態」より先に取る
- キーワードが行をまたぐときは、その語の前で改行する
