# 一騎打ち

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | スペル |
| コスト | 3 |
| 投入枚数 | 3 |

## 効果

敵キャラクター1体に4ダメージを与える。不屈：代わりに破壊する

## 絵

### 外見

ガイルとグラークがぶつかっている。ガイルは22歳の男性で、短く刈った灰褐色の髪、鋼色の瞳、頬と腕に切り傷の痕、擦り切れた革鎧に赤い腰布。グラークは人ではない魔族で、ガイルの2倍の背丈がある。鉄錆色の分厚い皮膚が鎧の板のように重なり、顔の下半分を鉄の顎が覆い、小さな黄色い目が光る。

### 情景

ガイルが長剣を振り上げ、振り下ろされたグラークの鉄の腕を真正面から受け止めている。刃と腕がぶつかった一点から白橙の火花が画面の上半分へ弾ける。ガイルは両足で地面を削りながら押し返している。

### 背景

沈む夕日の赤い逆光。二人の輪郭が赤く縁取られている。
