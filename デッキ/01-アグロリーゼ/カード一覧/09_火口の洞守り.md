# 火口の洞守り

| 項目 | 内容 |
|---|---|
| クラス | ウィザード |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

- 守護
- 死亡時：デッキからスペルを1枚手札に加える

## フレーバー

「火山が……怒っている……なぜだ……わからぬ……」

## 絵

### 外見

火山岩の重厚な鎧を全身にまとった火口の洞の番人。兜の奥は影で顔が見えない。鎧の継ぎ目から熱が漏れている。人の倍ほどの体格。

### 情景

火口へ続く洞の入り口に立ちふさがり、岩の裂け目から噴き出そうとする火柱を、巨大な玄武岩の板で押さえ込んでいる。足を踏ん張り、両腕で板を岩壁へ押し当てて動きを止めている。板の縁から炎と火の粉が噴きこぼれる。あおり気味に捉えて体格の大きさを見せる。

### 背景

火山の火口の底。溶けた岩の赤い光が下から照らす。人の営みも町も見えない。
