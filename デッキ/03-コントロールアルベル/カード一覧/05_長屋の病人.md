# 長屋の病人

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 0 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

死亡時：敵キャラクター1体に3ダメージ

## フレーバー

聖堂の裏手の長屋は、空いたことがない。

## 絵

### 外見

50代の女性。乱れた白髪交じりの髪、落ちくぼんだ灰色の瞳。血の気の無い顔。粗末な寝間着の肩に毛布を掛けている。それでも頑なに生きている、消えない目つき。

### 情景

藁の寝台の上で身を起こし、痩せた腕をまっすぐ画面外へ突き出している。**眉を上げ、歯を食いしばった、最後の力を振り絞る顔。**

胸元に集まった白い光が抑えきれずに膨らみ、腕の先へ流れ出そうとしている。**倒れる間際に何かを撃ち返す寸前だと分かるように描く。**

### 背景

施療院。ランプの明かりが暖かい。
