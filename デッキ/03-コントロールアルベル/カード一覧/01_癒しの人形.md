# 癒しの人形

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 1 |
| 攻撃力 | 1 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

- 召喚時：強化「+0/+1」を行う
- 死亡時：自由強化を1回行う

## フレーバー

ある男の救済は人を冷たくする。

## 絵

### 外見

人の膝ほどの背丈の、縫い目が見える小さな布人形。淡い白い光で動いている。腕に小さな包帯を巻いている。顔は黒い糸で縫った目と口だけ。意思を持たない道具であり、人でも生き物でもない。

### 情景

短い両手を差し伸べて癒しを差し出している。

### 背景

施療院。ランプの明かりが暖かく満ちている。
