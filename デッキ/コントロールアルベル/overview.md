# コントロールアルベル

単体除去・回復・ドローで相手の脅威を1枚ずつさばき、試合を長引かせるプリーストのコントロール。

| 項目 | 内容 |
|---|---|
| リーダー | アルベル |
| クラス | プリースト |
| アーキタイプ | コントロール |
| 舞台 | 聖の町 サンクトゥム |
| 合計枚数 | 40 |

## 勝ち筋と負け筋

- **勝ち筋**：相手が息切れしたあと、守護の大型と「聖獣キメラ」の反撃で盤面を制圧する
- **負け筋**：軽い受け札が薄く、序盤から高速で展開されると回復が間に合わない
- **とどめ**：「偽善のミゼリア」「聖鳥リフルエル」の守護大型と、回復連動で飛ぶキメラのダメージ

## デッキ固有能力

- **消耗**：相手の手札が2枚以下なら、続く効果が発動する
  - ex) `消耗：+2/+2する` → 相手の手札が2枚以下なら+2/+2する
- **聖徒**（種族タグ）：サンクトゥムに仕える者。「老司祭ドラン」「聖鳥リフルエル」が呼び出す対象

## 回し方

### 序盤（1〜3ターン）
「癒しの人形ホミ」「長屋の病人」「傷ついた巡礼者」の守護と自己回復で時間を稼ぎ、「小さな手当て」「記録を繰る」で手札を保つ。

### 中盤（4〜6ターン）
「聖獣キメラ」を置くと、以降の回復1回ごとに2ダメージが飛んで盤面をさばける。「聖騎士ザキエル」で脅威を1体、「怒れる聖職者アン」で横並びを一掃する。

### 終盤（7ターン〜）
「偽善のミゼリア」「聖鳥リフルエル」の守護大型でターンを止める。リフルエルは聖徒を追加で呼び、「老司祭ドラン」と合わせて「怪我をした修道女キーラ」「聖騎士ザキエル」を使い回す。

### 仕掛けの回り方
決め手が細いぶん、「聖獣キメラ」の回復連動ダメージと守護大型でターンを返し続け、相手の息切れを待つ。**「消耗」はこのデッキの想定キーワードだが、現状の40枚に参照カードは無い。**

### 有利不利
- **有利**：単体で殴ってくる中速デッキ。1枚ずつさばける
- **不利**：横展開とバーンの高速アグロ。回復が追いつかない
- **五分**：同型コントロール。ドローとフィニッシャーの質勝負

## 見た目の共通ルール

1. **光源はランプと後光。** 基調は象牙色、古びた金、柔らかい鳩羽鼠。差し色に淡い白の後光。埃の中を差す聖堂の光をテーマ。派手な原色は使わない。
2. **力の見た目は白い光の輪で統一する。** 力が働いているところには、柔らかい白い後光か光の輪が必ず出る。魔法陣や記号は使わない。**蘇生も回復とまったく同じ光で描く。**骨、腐敗、緑や紫の炎は一切使わない。立った死人は、治った人と見分けがつかない。
3. **サンクトゥムは最初から最後まで暖かい。** コストが上がっても光は濁らせない。施療院はランプの明かりが満ち、聖堂は掃き清められ、長屋には人が居る。壊れた聖堂も、荒れ果てた景色も描かない。周りの人物は普段どおりの暮らしを続けていて、誰も異変に気づいていない。
4. **恐怖はザキエルとミゼリアだけが持ち込む。** この二人が画面にいるときも背景は暖かいままにして、二人の周りの光だけを白く強くし、影を硬くする。剣も牙も向けていないのに、そこだけ温度が違う。この対比が唯一の恐怖の描き方。
5. **病人と聖職者で描き分ける。** 病人（種族タグの無い人間）は粗末な寝間着や擦り切れた旅装、血の気の無い肌、包帯や添え木。聖職者（聖徒）は清潔な祭服か修道服、背筋が伸び、身なりが整っている。どちらもサンクトゥムの人間なので、黒髪か白髪交じりで瞳は灰色。
6. **疲れ切っているのはアルベルだけ。** 目の下の隈と擦り切れた雰囲気は彼一人にしか描かない。病人は病んでいるだけ、聖職者は健やか。町でただ一人、彼だけが誰よりも長く起きている。
