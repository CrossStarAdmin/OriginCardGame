# 傷ついた巡礼者

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 2 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

- 守護
- 召喚時：このキャラクターは2ダメージを受ける

## 絵

### 外見

40代の男性。伸びた灰色の髪と無精髭、落ちくぼんだ灰色の瞳。破れた旅装の外套。片腕を血の滲む三角巾で吊っている。長く歩いてきた者の、痩せて頑固な雰囲気。

### 情景

もう一方の腕で使い込んだ木の盾を掲げ、退こうとしない。

### 背景

まだ聖堂が機能している頃。ランプの明かりが暖かい。
