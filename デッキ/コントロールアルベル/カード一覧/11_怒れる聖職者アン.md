# 怒れる聖職者アン

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |
| 種族タグ | 聖徒 |

## 効果

召喚時：敵キャラクター全体に3ダメージを与え、味方全体のHPを3回復する

## フレーバー

「ムカつくムカつくムカつく～っ！！！」

## 絵

### 外見

アン。30代の女性。頭巾を後ろへ払い落としていて、束ねた長い黒髪が乱れている。灰色の瞳。**目を見開き、歯を食いしばって怒っている。**

聖堂の簡素な灰色の祭服。身なりは清潔で背筋が伸びている。裸足で、足はきれいに洗われている。巡礼を終えてそのまま聖堂に仕えることを選んだ者。

### 情景

跪くのをやめて立ち上がり、両腕を左右へ大きく払っている。そこから白い光の輪が一気に外へ広がっていく。

**同じ光が、味方には触れて傷を塞ぎ、敵には叩きつけられている。**攻撃と治療が同じ光であることが分かるように描く。

怒りは炎や赤で表さない。**強すぎる白い光と、張り詰めた顔だけで出す。**

### 背景

聖堂の礼拝堂。ランプの明かりが暖かい。
