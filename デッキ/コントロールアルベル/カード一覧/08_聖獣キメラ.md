# 聖獣キメラ

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 3 |
| HP | 5 |
| 投入枚数 | 3 |

## 効果

味方リーダーのHPが実際に回復するたび、1体に2ダメージを与える

## 絵

### 外見

人の3倍ほどの体躯を持つ聖なる巨獣。獅子の体に、山羊の第二の頭と羽毛の鷲の翼。たてがみに沿って淡い金の光が燃えている。巡礼路を守るために飼われた獣で、人ではない。

### 情景

咆哮しながら前へ踏み出している。

### 背景

聖堂が手に負えなくなった頃。光が濁り始めている。
