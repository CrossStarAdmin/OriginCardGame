# 聖獣キメラ

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 2 |
| HP | 5 |
| 投入枚数 | 3 |

## 効果

守護
召喚時：リーダーのHPを2回復
死亡時：敵ユニット1体に2ダメージ

## 絵

### 外見

人の3倍ほどの体躯を持つ聖なる巨獣。獅子の体に、山羊の第二の頭と羽毛の鷲の翼。たてがみに沿って淡い金の光が燃えている。巡礼路を守るために飼われた獣で、人ではない。

### 情景

咆哮しながら前へ踏み出している。

### 背景

晴れた巡礼路。木漏れ日が暖かい。
