# 怪我をした修道女キーラ

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |
| 種族タグ | 聖徒 |

## 効果

- 守護
- ターン終了時：味方全体のHPを1回復する

## 絵

### 外見

20代前半の女性。頭巾から覗く短い黒髪、灰色の瞳。灰色の質素な修道服で、身なりは清潔。生真面目で気の強い雰囲気。

**片足を負傷していて、膝から下に厚く包帯を巻いている。**添え木が当ててある。

### 情景

寝台の縁に腰かけ、怪我をした足を投げ出したまま、上半身だけを前に乗り出している。片腕を横に伸ばして背後の誰かを庇い、空いた手から柔らかい守りの後光が広がる。

すぐ横の壁に松葉杖が立てかけてあり、手を伸ばせば届く位置にある。**「本当は立って働きたいのに座らされている」**という顔。**苛立ちではなく、じっと堪えている表情**にする。

### 背景

施療院。ランプの明かりが暖かい。
