# 修道女キーラ

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |
| 種族タグ | 聖徒 |

## 効果

- 守護
- ターン終了時：味方全体のHPを1回復する

## 絵

### 外見

20代前半の女性。頭巾から覗く短い黒髪、灰色の瞳。灰色の質素な修道服。腰に名簿の束を提げ、小さな円盾を持つ。生真面目で気の強い雰囲気。

### 情景

片腕を伸ばして背後の誰かを庇い、空いた手から柔らかい守りの後光が広がる。

### 背景

まだ聖堂が機能している頃。ランプの明かりが暖かい。
