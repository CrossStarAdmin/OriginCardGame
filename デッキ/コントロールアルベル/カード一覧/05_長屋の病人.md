# 長屋の病人

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 1 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

ターン終了時：このキャラクターのHPを1回復する

## 絵

### 外見

50代の女性。乱れた白髪交じりの髪、落ちくぼんだ灰色の瞳。血の気の無い顔。粗末な寝間着の肩に毛布を掛けている。それでも頑なに生きている、消えない目つき。

### 情景

藁の寝台の上で身を起こし、胸元に淡い治癒の光が集まっている。

### 背景

まだ聖堂が機能している頃。ランプの明かりが暖かい。
