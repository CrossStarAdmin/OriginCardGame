# 祈る巡礼者

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |
| 種族タグ | 聖徒 |

## 効果

召喚時：敵キャラクター全体に2ダメージを与え、味方キャラクター全体のHPを2回復する

## 絵

### 外見

30代の女性。頭巾から零れる長い黒髪、閉じた目。埃をかぶった巡礼の外套。裸足で、足裏は歩き通しで傷んでいる。すべてを預けきった静かな雰囲気。

### 情景

頭を垂れ両手を組んで跪き祈っている。そこから白い光の輪が地表へ広がっていく。

### 背景

聖堂が手に負えなくなった頃。光が濁っている。
