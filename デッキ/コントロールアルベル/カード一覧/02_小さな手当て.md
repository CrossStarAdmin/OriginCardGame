# 小さな手当て

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | スペル |
| コスト | 1 |
| 投入枚数 | 3 |

## 効果

味方1体のHPを2回復する。カードを1枚引く

## 絵

### 外見

アルベル（30代の男性。短く整えた黒髪、疲れを帯びた灰色の瞳、目の下に濃い隈。装飾の無い象牙色と灰色の祭服）が、寝台の患者の腕に巻いた布に手をかざしている。眉を寄せ、口を半開きにした、あからさまに面倒くさそうな顔。姿勢も少し前かがみで気が抜けている。

患者は40代の男の病人。粗末な寝間着で痩せているが、顔は明るい。

### 情景

布の下から柔らかく暖かい白い光が広がり、傷が塞がっていく。患者は喜んで身を起こし、アルベルの手を取ろうとしている。

アルベルは面倒くさそうな顔のまま手を引っ込めない。**口元だけがわずかに緩んでいて、悪い気はしていないと分かる。**その落差が見どころ。

### 背景

施療院。ランプの明かりが暖かい。
