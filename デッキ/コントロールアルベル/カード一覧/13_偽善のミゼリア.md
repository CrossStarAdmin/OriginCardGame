# 偽善のミゼリア

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 7 |
| 攻撃力 | 4 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

- 守護
- 召喚時：敵全体に4ダメージを与える

## 絵

### 外見

人より頭ひとつ背の高い、細身の魔族。顔立ちは整った女性のものだが、瞳孔の無い白い目と、血の気の無い灰白色の肌をしている。頭に繊細な黒い角。流れるような白と金の聖職者の衣をまとう。**温かく慈悲深い微笑みが、目まで届いていない。**人ではなく、幼さや愛嬌は一切無い。

### 情景

崩れた礼拝堂に立ち、祝福するように両腕を開く。そこから洗い流すような白い光の波が押し寄せる。

### 背景

聖堂が壊れたあと。白すぎる光が画面を灼いている。
