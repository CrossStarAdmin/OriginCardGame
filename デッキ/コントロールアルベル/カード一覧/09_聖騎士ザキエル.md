# 聖騎士ザキエル

| 項目 | 内容 |
|---|---|
| クラス | 司祭 |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |
| 種族タグ | 聖徒 |

## 効果

召喚時：敵キャラクター1体を破壊する

## 絵

### 外見

30代の男性。短く刈った金髪、澄んだ灰色の瞳。肩幅が広く、手入れの行き届いた淡い金縁の鎧をまとう。穏やかで整った顔立ち。**自分が善いことをしていると信じ切っている**、迷いの無い雰囲気。

### 情景

ランプの灯る施療院の寝台の上に立ち、抜いた剣を恐ろしいほど優しく下げ持つ。顔は憐れみに満ちている。

### 背景

聖堂が手に負えなくなった頃。光が濁っている。
