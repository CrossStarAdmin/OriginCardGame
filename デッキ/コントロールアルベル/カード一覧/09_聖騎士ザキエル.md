# 聖騎士ザキエル

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |
| 種族タグ | 聖徒 |

## 効果

召喚時：敵キャラクター1体を破壊する

## 絵

### 外見

30代の男性。短く刈った金髪、澄んだ灰色の瞳。肩幅が広く、手入れの行き届いた淡い金縁の鎧をまとう。穏やかで整った顔立ち。隈も汚れもなく、身なりに乱れが無い。**自分が善いことをしていると信じ切っている**、迷いの無い雰囲気。

### 情景

普段どおりの施療院で、寝台のかたわらに立ち、抜いた剣を恐ろしいほど優しく下げ持つ。顔は憐れみに満ちている。周りの修道女や病人は手を動かしたままで、誰も彼を見ていない。

### 背景

施療院。ランプの明かりは暖かいまま。ただ彼の周りの光だけが白く強く、影が硬い。
