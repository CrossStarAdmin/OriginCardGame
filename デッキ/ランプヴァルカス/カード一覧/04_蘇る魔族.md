# 蘇る魔族

| 項目 | 内容 |
|---|---|
| クラス | 魔族 |
| 種類 | スペル |
| コスト | 2 |
| 投入枚数 | 2 |

## 効果

- 自分の墓地のカード1枚を手札に加える
- 解放：代わりに、自分の墓地のカード2枚を手札に加える

## 絵

### 外見

人ではない、画面を占めるのは現象そのもの。地の底へ沈んだ魔族の骸を、霊脈の光の筋が掬い上げている。

### 情景

黒い岩の地面に深い裂け目が口を開け、その底から青白い光の筋が何十本も伸びている。筋は倒れた魔族2体の骸に幾重にも絡みつき、画面の上半分へ引き上げている。引き上げられている魔族は、どちらも白目の無い瞳に青白い光が灯り直しかけていて、垂れた指先がわずかに動いている。

### 背景

檻の外周の地の底。引き上げる光の筋だけが明るく、周りは黒い岩と闇に沈んでいる。
