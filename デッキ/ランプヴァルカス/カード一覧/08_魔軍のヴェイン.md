# 魔軍のヴェイン

| 項目 | 内容 |
|---|---|
| クラス | 魔族 |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 5 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

- 突進・必殺
- 召喚時：全解放：速攻を得る

## 絵

### 外見

人ではない、人より頭ひとつ背の高い20代前半の男性のようなキャラクター。魔族だけど人にとても似ており、長髪の白い髪を持つものすごいイケメン。体格も細い。顔の右半分にはピアスをむちゃくちゃしている。伸びた白髪を首の後ろで無造作に束ね、瞳には白目があり、灰色をしている。腰には黒い剣を収めている。感情の読めない、どこにも属していない顔。

### 情景

岩場の上から、腕を組み、片足を掛け、魔王城を見下ろしている。軽蔑の目を向け、今にも反逆するような様子。


### 背景

檻の外周の岩場。霊脈の光が地面の割れ目から低く漏れ、彼の足元だけを下から照らしている。魔王城がかすかに見える。上半分は暗い。
