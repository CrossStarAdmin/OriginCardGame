# 六罪 ヴェルド

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | キャラクター |
| コスト | 7 |
| 攻撃力 | 4 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

- 速攻
- 召喚時：敵キャラクター全体に3ダメージを与える

## 絵

### 外見

人ではない、人より頭ひとつ背の高い痩身の魔族。ひび割れた黒曜石の肌をしていて、その裂け目が溶岩色に光っている。後方へ流れた2本の角。白目の無い瞳。上半身には何もまとわず、腰から下だけを焼け焦げた布で覆っている。人を見下している、どこか感嘆すら含んだ微笑み。幼さや愛嬌は一切無い。

### 情景

魔界の岩の谷で、自分の3倍はある魔獣を片手で殴り倒した直後。腰を落として体をひねり、振り抜いた腕をまだ下ろしていない。足元と周りには、同じように倒れた魔獣が何体も転がっている。倒したものを、焼け落ちた町を眺めるときと同じ顔で見下ろしている。

### 背景

魔界の深部の岩の谷。地面の割れ目から霊脈の光が溢れ、彼の全身を下から強く照らしている。肌の裂け目の溶岩色と光が混ざっている。光の届かない谷の上と奥は黒く沈んでいる。
