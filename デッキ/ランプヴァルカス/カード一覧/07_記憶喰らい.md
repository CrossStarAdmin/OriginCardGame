# 記憶喰らい

| 項目 | 内容 |
|---|---|
| クラス | 魔族 |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

- 召喚時：敵リーダーのパワーを-1する。味方リーダーのパワーを+1する

## 絵

### 外見

人ではない、細長い影のような魔族。人と同じ背丈だが、体の厚みがほとんど無く紙のように薄い。煤けた黒い肌、後頭部から一直線に伸びた1本の細い角、白目の無い青白く光る瞳。衣服は着ておらず、輪郭が煙のようにほどけている。口だけが不自然に大きく裂けている。

### 情景

膝をついた人間の兵士に背後から覆いかぶさり、大きく裂けた口を兵士の頭のすぐ上へ寄せて、頭から立ちのぼる光の筋を吸い込んでいる。兵士は兜で顔が隠れていて、力なくうなだれている。光の筋は兵士の側では細く途切れ、口に近づくほど太く束になっている。細長い指の黒い爪が兵士の肩に深く食い込んでいる。吸い込まれた光が薄い体の中を透けて流れていくのが見える。目はこちらを見ている。

### 背景

檻の外周の岩場。地面の割れ目から漏れる霊脈の光が二人を下から照らし、周りは黒く沈んでいる。
