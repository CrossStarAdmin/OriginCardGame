# 霊脈喰らい

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 4 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

- 召喚時：敵1体に3ダメージを与える
- 死亡時：自分の最大MPを+1する

## 絵

### 外見

人ではない、四つ足の巨大な獣型の魔族。人の3倍の体長がある。濡れた黒い甲殻に覆われた背、後ろへ寝た太い2本の角、白目の無い青白く光る瞳が顔の左右に4つ。衣服は着ていない。腹側の甲殻が透けていて、飲み込んだ光が体の中を流れているのが見える。獣の顔だが、目つきに知性がある。

### 情景

黒い岩の割れ目に頭を突っ込み、四肢を踏ん張って背を丸め、割れ目から昇る光の束をまとめて飲み下している。首から背にかけて光が流れ込んでいくのが甲殻越しに見える。前脚が岩を割って沈み込んでいる。顔の片側だけをこちらへ向けている。

### 背景

檻の外周の岩場。飲み下している光の束が明るく、獣の胴を下から照らしている。上半分と奥は暗い。
