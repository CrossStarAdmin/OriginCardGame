# 檻の番人

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 1 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

- 守護
- 相手の効果の対象にならない
- 召喚時：解放：+1/+3する

## 絵

### 外見

人ではない、ずんぐりと分厚い魔族。人と同じくらいの背丈だが、横幅は人の2倍ある。石を積んだような灰黒色の肌、頭の左右から真横へ伸びた短い角、白目の無い赤く光る瞳。錆びた鉄板を鎖で体に括りつけただけの粗末な防具。表情が動かず、千年同じ場所に立ち続けてきた鈍さがある。

### 情景

黒い岩の通路を塞ぐように、両足を大きく開いて立ちはだかっている。両腕を横へ広げて通路の幅いっぱいを埋め、体重を前へかけている。視線はまっすぐこちらを見据えている。足元の岩に体重で沈んだ跡がついている。

### 背景

檻の外周の狭い通路。足元の岩の割れ目から霊脈の光がかすかに漏れ、それ以外は黒く沈んでいる。
