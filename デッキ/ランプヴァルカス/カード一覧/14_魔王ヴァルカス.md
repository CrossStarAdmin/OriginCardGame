# 魔王ヴァルカス

| 項目 | 内容 |
|---|---|
| クラス | 魔族 |
| 種類 | キャラクター |
| コスト | 10 |
| 攻撃力 | 8 |
| HP | 8 |
| 投入枚数 | 3 |

## 効果

- 速攻・守護・必殺

## 絵

### 外見

人ではない、魔族の王。人の3倍の背丈を持つ巨躯。異形。
ものすごく筋肉質で、青黒色の肌を持っている。頭の左右から2本の角が上へ伸びて、威厳を放っている。全生物を侮蔑するような赤い目。
短髪の白い髪を持ち、黒色の長い羽衣をまとう。背には蝙蝠のような翼。幼さや愛嬌はない。
片手におぞましい槍を握っている。

### 情景

座り続けていた玉座から立ち上がり、玉座を背後に置き去りにして大きく一歩を踏み出したところ。翼を大きく広げ、握った槍を振りかぶって、こちらへ突き下ろそうとしている。踏み出した足の下で床が砕け、割れ目から霊脈の光の筋が何本も噴き上がって体に吸い込まれていく。赤い目がこちらを見下ろしている。全身を画面に収める。

### 背景

玉座の間。背景には血が飛び散っている。床の割れ目から溢れる霊脈の光が巨躯を下から照らし、そこから離れるほど黒く沈んでいる。
