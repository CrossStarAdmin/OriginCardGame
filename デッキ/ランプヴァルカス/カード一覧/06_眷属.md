# 眷属

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 2 |
| HP | 1 |
| 投入枚数 | 3 |

## 効果

- 突進
- 死亡時：カードを1枚引く
- 召喚時：解放：「眷属」1体を自分の場に出す

## フレーバー

「ぐるるるる……」王の足元でだけ、牙を収める。

## 絵

### 外見

人ではない、痩せた四つ足の獣型の魔族。四つ足で立って人の腰ほどの高さ、体長は人の背丈ほどある。煤けた黒い短毛、背骨の浮き出た細い胴、額から前へ突き出した1本の短い角、白目の無い青白く光る瞳。首に細い黒鉄の輪をはめられている。主に放たれた猟犬のように、獲物だけを見据える目つき。

### 情景

黒い岩場を低く身を沈めて駆け、前脚を大きく伸ばしてこちらへ飛びかかる瞬間。四肢の爪が岩を掻き、蹴った跡に砕けた岩片が散っている。後方の暗がりでは、同じ姿の眷属の青白い瞳がもう一対光っている。

### 背景

檻の外周の岩場。駆ける足元の割れ目から漏れる霊脈の光が胴を下から照らし、奥は黒く沈んでいる。
