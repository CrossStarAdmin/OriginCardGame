# 無様な魔物

| 項目 | 内容 |
|---|---|
| クラス | 魔族 |
| 種類 | キャラクター |
| コスト | 1 |
| 攻撃力 | 1 |
| HP | 1 |
| 投入枚数 | 3 |

## 効果

- 死亡時：1体に2ダメージを与える

## 絵

### 外見

人ではない、痩せこけた小柄な魔族。人の胸ほどの背丈しかない。灰色の乾いた肌、白目の無い黄色く光る瞳。腰に粗い布を巻いただけの姿。

### 情景

黒い岩場で足をもつれさせ、前のめりに転びかけながら、握った尖った石片を振りかぶってこちらへ飛びかかってくる。口を大きく開けて喚いている。痩せた胸の内側に青白い光の筋が細く透け、今にも弾けそうに脈打っている。

### 背景

檻の外周の岩場。足元の割れ目から漏れる霊脈の光だけが下から当たり、周りは黒い岩と闇に沈んでいる。
