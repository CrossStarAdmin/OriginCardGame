# 玉座の使い魔

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

- 召喚時：デッキからコスト8以上のカード1枚を手札に加える

## フレーバー

王の使いになると決めた。呼ばれる日を、石段で待っている。

## 絵

### 外見

人ではない、翼を持つ小柄な魔族。人の腰ほどの背丈しかない。灰紫色の薄い肌、頭の左右に小さく巻いた2本の角、白目の無い青白く光る瞳。皮膜の翼を背に畳んでいる。首に細い黒鉄の輪をはめられている。使い走りらしい落ち着きの無さがあり、常に何かを窺っている。

### 情景

玉座へ続く黒い石段の途中に、片足だけを段にかけて身を低くとまっている。翼を半分だけ開いて振り返り、石段の上のほうへ視線を投げている。呼ばれるのを待っている姿勢。

### 背景

玉座へ続く石段。段の割れ目から霊脈の光が細く漏れて体を下から照らし、石段の上も下も黒く沈んでいる。
