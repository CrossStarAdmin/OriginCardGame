# 砦の古参兵

| 項目 | 内容 |
|---|---|
| クラス | ウォリアー |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 4 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

- 守護
- 召喚時 不屈：味方リーダーが次に受けるダメージを0にする

## 絵

### 外見

50代の男性。白髪の混じった灰褐色の髪を短く刈っている。鋼色の瞳で、左目の上から頬へ古い切り傷が走る。へこんだ鉄兜と、傷だらけの丸い鉄の盾。革鎧の腰に赤い布。歯を食いしばった、しぶとい雰囲気。

### 情景

崩れかけた城壁の上で、丸盾を正面に構えて両足を踏ん張り、一歩も退かない。盾の縁で受けた刃から白橙の火花が散り、盾の脇から自分の剣を突き出している。

### 背景

沈む夕日の赤い逆光。兵士の輪郭が赤く縁取られ、城壁の影が長く伸びている。
