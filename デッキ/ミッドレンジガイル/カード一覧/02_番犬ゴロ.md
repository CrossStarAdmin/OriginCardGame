# 番犬ゴロ

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 1 |
| HP | 5 |
| 投入枚数 | 2 |

## 効果

- 守護
- 召喚時：味方リーダーに2ダメージを与える

## 絵

### 外見

大型の番犬。人ではない。立った高さが人の腰ほどある。灰色の短い毛並みで、片耳の先が欠けている。首に鋲を打った赤い革の首輪。筋肉の張った太い四肢。

### 情景

砦の門の前で四肢を地面に踏ん張り、牙を剥いて正面に吠えている。背後の門を守るように、体を門の真ん中に置いている。

### 背景

乾いた昼の日光。砂色の石壁が明るく照らされている。
