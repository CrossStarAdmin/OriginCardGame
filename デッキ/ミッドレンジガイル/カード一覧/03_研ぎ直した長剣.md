# 研ぎ直した長剣

| 項目 | 内容 |
|---|---|
| クラス | ウォリアー |
| 種類 | 武器 |
| コスト | 2 |
| 攻撃力 | 2 |
| 耐久力 | 2 |
| 投入枚数 | 3 |

## 効果

この武器が破壊されたとき、カードを1枚引く

## 絵

### 外見

使い込まれた鉄の長剣。刃こぼれを研ぎ直した跡が波のように残り、柄に巻いた革は擦り切れて黒ずんでいる。鍔は飾りの無い鉄の棒。

### 情景

鍛冶場の裏の砥石に、日に焼けた両手がこの長剣の刃を押し当てて研いでいる。刃と砥石のあいだから白橙の短い火花が散る。剣が画面の中心を斜めに横切る。

### 背景

乾いた昼の日光が鍛冶場の裏を明るく照らしている。
