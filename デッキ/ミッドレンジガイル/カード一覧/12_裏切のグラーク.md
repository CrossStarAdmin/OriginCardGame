# 裏切のグラーク

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 5 |
| HP | 5 |
| 投入枚数 | 2 |

## 効果

召喚時：味方リーダーに3ダメージを与え、敵キャラクター全体に3ダメージを与える

## 絵

### 外見

人ではない魔族。人の2倍の背丈がある、分厚い巨躯。鉄錆色の分厚い皮膚が鎧の板のように何枚も重なっている。顔の下半分を鉄の顎が覆い、小さな黄色い目が光る。太い両腕の先は鉄の塊のような拳。人を見下ろして愉しんでいる雰囲気で、幼さや愛嬌は一切無い。

### 情景

砦の城壁の上に腰を下ろし、片膝に肘をついて下の門を見下ろしている。門からは何本もの縄が垂れて風に揺れている。黄色い目が細まり、鉄の顎の奥で笑っている。

### 背景

厚い曇天。色が失われ、砦全体に重い影が落ちている。
