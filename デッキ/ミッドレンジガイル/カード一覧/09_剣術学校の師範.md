# 剣術学校の師範

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 4 |
| HP | 5 |
| 投入枚数 | 3 |

## 効果

召喚時：味方リーダーのHPを5回復する

## 絵

### 外見

60代の男性。後ろへ撫でつけた灰褐色の髪はほとんど白くなっている。鋼色の瞳。日に焼けた肌に深い皺と古い切り傷の痕。袖をまくった簡素な稽古着に、使い込んだ鉄の籠手。背筋がまっすぐ伸びた、厳しくも穏やかな雰囲気。

### 情景

土の稽古場に立ち、若い剣士の構えた長剣の刃に自分の籠手を当てて、角度を直している。視線は刃の向きに落ちている。

### 背景

乾いた昼の日光が稽古場の土を明るく照らしている。
