# 鉄の大剣

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | 武器 |
| コスト | 4 |
| 攻撃力 | 4 |
| 耐久力 | 2 |
| 投入枚数 | 3 |

## 効果

不屈：攻撃力+2

## 絵

### 外見

人の胸まで届く長さの、分厚い鉄の大剣。飾りの無い無骨な刃に、深い刃こぼれがいくつも残っている。柄には赤い布が巻かれている。

### 情景

ガイルが両手でこの大剣を振り下ろし、刃が鉄の盾に食い込んでいる。ぶつかった一点から白橙の火花が画面の上半分へ噴き上がる。ガイルは短く刈った灰褐色の髪と鋼色の瞳、頬に切り傷のある22歳の男性で、画面の下半分に入る。

### 背景

沈む夕日の赤い逆光。大剣とガイルの輪郭が赤く縁取られている。
