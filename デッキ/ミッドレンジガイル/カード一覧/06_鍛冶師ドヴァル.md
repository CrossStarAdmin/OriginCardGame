# 鍛冶師ドヴァル

| 項目 | 内容 |
|---|---|
| クラス | ウォリアー |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 2 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

召喚時：味方リーダーが武器を装備しているなら、その武器の攻撃力を+2する。不屈：代わりに+3する

## 絵

### 外見

50代の男性。白髪の混じった灰褐色の短い髪と、短く刈った顎髭。鋼色の瞳。煤で黒ずんだ革の前掛けを着け、太い前腕に古い火傷と切り傷の痕。口を引き結んだ、無口な職人の雰囲気。

### 情景

金床の前に両足を据え、真っ赤に焼けた鉄の刃に槌を振り下ろしている。打った一点から白橙の火花が四方へ散る。視線は刃から一瞬も離れない。

### 背景

窓から差す乾いた昼の日光と、炉の赤い照り返し。鍛冶場の中は明るい。
