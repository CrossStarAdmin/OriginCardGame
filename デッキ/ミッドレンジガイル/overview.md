# ミッドレンジガイル

リーダー自身が武器で敵キャラクターを斬って盤面を取り、傷ついてHPが15以下になると「不屈」で強くなる。最後は兄ゲインで盤面を流し、大型の武器で顔を殴り切るウォリアーのミッドレンジ。

| 項目 | 内容 |
|---|---|
| リーダー | ガイル |
| クラス | ウォリアー |
| アーキタイプ | ミッドレンジ |
| 舞台 | 砦の町 ロダン |
| 合計枚数 | 40 |

## 勝ち筋と負け筋

- **勝ち筋**：8〜10ターン目、「兄ゲイン」の全体4ダメージで盤面を流し、「ドヴァルの遺作」の貫通と「立てなくなるまで」で顔を削り切る
- **負け筋**：手札を増やせるのは「研ぎ直した長剣」が壊れたときの1枚だけ。除去と回復を重ねるコントロールには、先に手札が尽きる
- **とどめ**：「ドヴァルの遺作」の貫通攻撃と、守護を越える「立てなくなるまで」。倒された「兄ゲイン」からデッキの遺作を装備し直し、耐久力を戻して殴り続ける

## デッキ固有能力

- **不屈**：味方リーダーのHPが15以下なら、続く効果が発動する
  - ex) `召喚時 不屈：味方リーダーが次に受けるダメージを0にする` → 召喚したとき、味方リーダーのHPが15以下なら、次に受けるダメージを0にする
  - ex) `不屈：攻撃力+2` → 味方リーダーのHPが15以下のあいだ、この武器の攻撃力が+2される
- 召喚時などの効果は、その効果を解決するときに1回だけ判定する。武器の常在効果は、条件を満たしているあいだだけ効く

## 回し方

### 序盤（1〜3ターン）
「ロダンの傭兵」「番犬ゴロ」「踏み込み」は自分にもダメージを与え、HPを15へ近づける。敵の小型は「研ぎ直した長剣」やパワースキルの「鍛錬の剣」でリーダーが斬る。長剣は壊れると1枚引けるので、パワースキルで上書きしても損をしない。

### 中盤（4〜6ターン）
HPが15以下に落ちたら、「鉄の大剣」が攻撃力6、「一騎打ち」が破壊、「砦の古参兵」が次のダメージを0にする守りになる。「鍛冶師ドヴァル」で装備中の武器の攻撃力を+2（不屈なら+3）する。横に並べられたら「裏切のグラーク」で敵キャラクター全体に3ダメージを与え、自分も3ダメージを受けて不屈に入る。HPが下がりすぎたら「剣術学校の師範」で5回復して立て直す。

### 終盤（7ターン〜）
「兄ゲイン」で敵キャラクター全体に4ダメージ、敵リーダーに2ダメージを与える。ゲインが倒されたら、デッキから「ドヴァルの遺作」を装備し直す。遺作は貫通を持ち、自分のターンに受けるダメージを3減らすので、大きい相手を斬っても傷つきにくい。守護で止められたら「立てなくなるまで」で、武器の攻撃力ぶんを敵リーダーに直接与える。

### 仕掛けの回り方
不屈は「鍛冶師ドヴァル」「鉄の大剣」「砦の古参兵」「一騎打ち」の12枚に乗る。HPを下げる手段は、リーダーの攻撃で受ける反撃、「ロダンの傭兵」の1、「踏み込み」の1、「番犬ゴロ」の2、「裏切のグラーク」の3。**HPが16以上のままだと、不屈持ちは素のカードになる。** 「剣術学校の師範」の回復と「ドヴァルの遺作」の軽減はHPを保つ側に働くので、不屈に入るか、HPを守るかを選びながら戦う。

### 有利不利
- **有利**：ランプ。前半の小型を武器で斬り続け、解放の前に大型武器で押し込める
- **不利**：コントロール。除去と回復で武器の耐久力を使い切らされ、手札を増やす手段が薄いので先に息切れする
- **五分**：アグロ。武器で盤面は取れるが、自分でHPを削るぶん顔に届かれやすい

### 素点の補足
- 「ロダンの傭兵」は1コストで2/2（素点4ちょうど）。自分への1ダメージは不屈の準備として働く
- 「番犬ゴロ」は2コストで1/5（守護込みの目安5に対し6）。自分への2ダメージで引いている
- 「踏み込み」は1コストで3ダメージ（目安2コスト）。自分への1ダメージで引いている
- 「裏切のグラーク」は5コストで5/5（全体3ダメージ込みの目安8に対し10）。自分への3ダメージで引いている
- 「兄ゲイン」は8コストで5/5（素点18）。全体4ダメージ・顔2点・死亡時の武器装備を持ち、目安を超えるエースとして置いている
- 武器の強さは `manual/` に基準が無いので、「攻撃力×耐久力 ≒ コスト×2」を仮の目安に置いている。敵キャラクターを斬ると反撃を受けるぶんも代償として数える
- 顔へ直接飛ぶダメージは「兄ゲイン」の2が3枚と、「立てなくなるまで」の5〜8が2枚で、合計16〜22前後。「鍛冶師ドヴァル」で武器を強くすると目安の15を超えるので、対戦で確かめる

## 未確定のルール

- 「砦の古参兵」の「次に受けるダメージを0にする」がいつまで続くか、重ねがけできるか、リーダーの攻撃で受ける反撃にも効くか
- 「ドヴァルの遺作」の「受けるダメージを-3する」が0未満にならないか、どのダメージに効くか

## 見た目の共通ルール

1. **光源は荒れ地の日光。** 基調は乾いた砂色、錆びた鉄色、煤けた灰。差し色にウォリアーの赤を、マント・腰布・旗にだけ使う。魔法の光で画面を照らさない。
2. **力の見た目は鋼と火花で統一する。** 力が働いているところには、刃と刃、刃と鉄がぶつかって散る白橙の短い火花が出る。炎・魔法陣・記号・光のオーラは使わない。武器はどれも使い込まれていて、刃こぼれと研ぎ跡が見える。
3. **三つの空で明暗を分ける。** グラークが来る前の日常は、乾いた昼の日光で明るく埃っぽく描く。グラークの支配下は、厚い曇天で色を失わせ、砦の影を重く落とす。ガイルが反撃に出るカード（ガイル本人・鉄の大剣・砦の古参兵・一騎打ち・ドヴァルの遺作・立てなくなるまで）は、沈む夕日の赤い逆光で人物の輪郭を強く縁取る。
4. **ロダンの人間は灰褐色の髪と鋼色の瞳。** 日に焼けた肌に、古い切り傷の痕がそのまま見えている。服装は革鎧と鉄の防具。グラークは人ではない鉄錆色の巨躯で、ロダンの人間の2倍の背丈がある。
