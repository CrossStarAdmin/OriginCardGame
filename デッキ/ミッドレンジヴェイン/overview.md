# ミッドレンジヴェイン

おうえんでパワーを溜め、パワースキル「揺れる魂」で白（ノア）と黒（黒いヴェイン）を裏返しながら、守る面と攻める面を切り替えて戦うデーモンのミッドレンジ。

| 項目 | 内容 |
|---|---|
| リーダー | ヴェイン |
| クラス | デーモン |
| アーキタイプ | ミッドレンジ |
| 舞台 | 町を持たない（千年前のノアの村と魔軍） |
| 合計枚数 | 40 |

## 勝ち筋と負け筋

- **勝ち筋**：8〜10ターン目、六罪で盤面を固め、パワースキルで黒へ裏返して攻撃力・必殺・突進を得た盤面で押し切る
- **負け筋**：白と黒の両方に枠を割くので、どちらかに振り切った相手に純度で負ける。裏返す手段の大半がパワースキルなので、おうえん持ちを除去されてパワーが溜まらないと、欲しい面に切り替えられない
- **とどめ**：黒に裏返した盤面の総攻撃と、「六罪 ガドル」の味方全体+2/+2

## デッキ固有能力

- **表裏**：リーダーは白と黒のどちらかの状態を持つ。対戦開始時は白
  - **裏返す**：白と黒を入れ替える。`裏返してよい` は、裏返すかどうかを選べる
  - **白：／黒：**：今の状態がそちらなら、続く効果が発動する
    - ex) `白：守護を持つ` → 自分が白のあいだ、守護を持つ
    - ex) `敵キャラクター1体に2ダメージを与える。黒：代わりに4ダメージを与える` → 自分が黒なら4ダメージを与える
  - **裏返ったとき**：自分の状態が変わった直後に発動する
- 常に効いている効果は、状態が変わった瞬間に切り替わる。召喚時やスペルの効果は上から順に解決するときに判定し、上の行で裏返っていれば裏返ったあとの状態で判定する

## 回し方

### 序盤（1〜3ターン）
白のまま「さまよう魂」の守護で受け、「魔軍の小鬼」「魔軍の剣兵」のおうえんと、自分で溜める1回でパワーを3に近づける。「気まぐれの一太刀」で小型を落とし、「呪剣ノア」は白なら攻撃するたびにHPを2回復する。

### 中盤（4〜6ターン）
パワーが3になったら「揺れる魂」を撃つ。**相手のターンは白の守護で受け、自分のターンに黒へ裏返して3ダメージを撃ち、攻撃力が上がった盤面で殴る。** 次に撃つときは白に戻して回復する。「罪の影」は裏返るたびに+1/+1され、「魔軍の伝令」はおうえんと裏返しを1枚で両方こなす。「黒いヴェイン」は黒のあいだ倒されても手札に戻る。

### 終盤（7ターン〜）
「六罪 グラーク」で大型を1体破壊し、「六罪 ネフィス」で横並びを流しながらHPを戻す。「六罪 ガドル」で味方全体を+2/+2し、黒に裏返して「魔軍一の剣」の必殺と「黒いヴェイン」の突進ごと押し切る。苦しいときは「千年の眠り」で裏返し、白なら6回復、黒なら敵キャラクター1体を破壊する。

### 仕掛けの回り方
表裏は「さまよう魂」「気まぐれの一太刀」「罪の影」「呪剣ノア」「魔軍の伝令」「逢瀬の記憶」「黒いヴェイン」「皆殺しの命令」「魔軍一の剣」「千年の眠り」の27枚に乗る。裏返す手段はパワースキルと「魔軍の伝令」「千年の眠り」の5枚で、パワーを溜めるおうえんは「魔軍の小鬼」「魔軍の剣兵」「魔軍の伝令」「魔軍一の剣」の11枚。パワーが3に戻れば、パワースキルは1ターンに何度でも撃てる。**おうえん持ちが並ばないとパワースキルが3ターンに1回になり、今の面に合わないカードが手札で腐る。** 六罪3種は状態に関係なく働く。

### 有利不利
- **有利**：ミッドレンジ。白の守護と回復で受け、黒で盤面を取り返す波で上回る
- **不利**：アグロ。パワーが溜まる前の序盤は白の守りが薄く、横並びに押し切られる
- **五分**：コントロール。「黒いヴェイン」の手札戻しで息切れしにくいが、全体除去でおうえん持ちを流されるとパワースキルが遅れる

### 素点の補足
- おうえんは `manual/` に基準が無いので、素点1ぶんとして数えている
- 「さまよう魂」は1コスト1/2（条件付きの守護と攻撃力+1込みの目安3ちょうど）
- 「魔軍の小鬼」は1コスト1/2、「魔軍の剣兵」は2コスト2/3。どちらもおうえん込みの目安ちょうど
- 「罪の影」は2コスト2/2（目安6に対し4）。裏返るたびに+1/+1され続ける
- 「呪剣ノア」は3コスト2/3（攻撃力×耐久力6、仮の目安コスト×2＝6）
- 「魔軍の伝令」は3コスト3/3（おうえんと裏返し込みの目安6ちょうど）
- 「黒いヴェイン」は4コスト4/4（目安10に対し8）。黒のあいだの突進と手札戻しで引いている
- 「魔軍一の剣」は5コスト5/4（おうえん・白の守護・黒の必殺込みの目安9ちょうど）
- 「気まぐれの一太刀」は2コストで2ダメージ（目安1コスト）、黒なら4ダメージ（目安3コスト）
- 「皆殺しの命令」は黒の全体2ダメージ（目安3コスト）と白の全体+0/+2の両面で4コスト
- 「千年の眠り」は黒の単体破壊（目安4〜6コスト）と白の6回復＋ドロー1の両面で5コスト
- 「六罪 グラーク」は6コスト5/5＋単体破壊（目安10）、「六罪 ガドル」は7コスト6/6＋全体+2/+2（目安12）、「六罪 ネフィス」は8コスト6/6＋全体2ダメージと回復（目安12）
- 顔へ直接飛ぶダメージは、パワースキル（黒）の1点と「六罪 ネフィス」の2点×2で、目安の15を大きく下回る

## 見た目の共通ルール

1. **光源は月明かりと、ノアの魂の光。** 基調は夜の黒、鈍い銀、擦り切れた外套の煤色。差し色は、白の力にだけ使う乳白色の柔らかな光。霊脈の青白い光、星の光、炎では照らさない。
2. **力の見た目は白い光の粒と黒い靄で統一する。** 白の力は、呪剣や手元からこぼれて、ゆっくり舞い上がる乳白色の光の粒。黒の力は、刃や体から滲み出して地を這い、光を吸う黒い靄。魔法陣・記号・星座・霊脈の筋は使わない。
3. **ノアと罪で明暗を分ける。** ノアに関わるカード（さまよう魂・気まぐれの一太刀・呪剣ノア・逢瀬の記憶・千年の眠り）は、月明かりの澄んだ夜か、木漏れ日の森で明るく描く。魔軍・罪・六罪のカード（魔軍の小鬼・魔軍の剣兵・罪の影・魔軍の伝令・黒いヴェイン・皆殺しの命令・魔軍一の剣・六罪3種）は、月の無い夜の暗がりに黒い靄を満たして描く。ヴェイン本人は、体の半分を月明かりと白い光、もう半分を黒い靄に沈める。
4. **人物の描き分け。** ヴェインは人ではない、人より頭ひとつ背の高い20代前半の男性のような魔族で、人にとても似たものすごく端正な顔立ち、細い体格、首の後ろで束ねた長い白髪、白目のある灰色の瞳、顔の右半分に多数のピアス。ノアは人間の若い女性で、亜麻色の長い髪を緩く編み、空色の瞳。剣に宿ったあとのノアは、全身が乳白色の光で半ば透けている。黒いヴェインはヴェインと同じ形の、黒い靄でできた人ではない影。魔軍の魔物と六罪は人ではなく、六罪は他のデッキと同じ姿で描く。
