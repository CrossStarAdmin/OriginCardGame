# 六罪 ガドル

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | キャラクター |
| コスト | 8 |
| 攻撃力 | 4 |
| HP | 9 |
| 投入枚数 | 3 |

## 効果

死亡時：「六罪 ガドル」を墓地から場に出す

## 絵

### 外見

魔族。人ではない。人より少し大きいくらいの背丈がある。異形。天狗の面相で、顔だけが焼けた朱色。そこから鴉の嘴のように長く鋭い鼻が突き出し、落ち窪んだ奥で金色の目が光る。口の端から牙が覗く。頭と顎から白い荒れ髪と髭が鬣のように伸びる。首から下は岩のような青黒の肌で、分厚い筋肉が盛り上がり、その下を暗い赤の筋が脈打っている。背には黒い羽根の巨大な翼を畳んでいる。巫女の服のようなものをまとっている。まっすぐで、豪快な雰囲気。幼さや愛嬌は一切無い。

### 情景

両足を大きく開いてどっしりと構えている。近くにいる人型の魔物相手に戦っている様。絵に移っている全ての魔物を払いのけ、圧勝している。背の黒い翼も腕と一緒に大きく広げている。余裕そうな顔で腹の底から笑っている。

### 背景

霊脈の光が差し込む魔界の荒野。基調は黒と鈍い鉛色。月も炎も無く、地面の割れ目から昇る霊脈の青白い燐光だけが下から全身を照らし、顎と胸を明るく、額に影を落としている。光の届かない奥は黒く沈んでいる。
