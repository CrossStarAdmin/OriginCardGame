# さまよう魂

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | キャラクター |
| コスト | 1 |
| 攻撃力 | 1 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

- 白：守護を持つ
- 黒：攻撃力+1

## 絵

### 外見

人の形をした魂。人ではない。人と同じ背丈で、全身が乳白色の淡い光でできていて半ば透けている。素朴な村人の服の形がぼんやりと見える。穏やかで、寂しげな雰囲気。

### 情景

月明かりの草原に足先を浮かせて漂い、両腕を大きく広げて、画面の手前に向かって立ちはだかっている。体の縁から光の粒がこぼれ、ゆっくり舞い上がっている。視線は正面。

### 背景

月明かりの澄んだ夜。草原が銀色に照らされ、明るい。
