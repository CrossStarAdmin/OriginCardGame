# 呪剣ノア

| 項目 | 内容 |
|---|---|
| クラス | デーモン |
| 種類 | 武器 |
| コスト | 3 |
| 攻撃力 | 2 |
| 耐久力 | 3 |
| 投入枚数 | 3 |

## 効果

- 白：攻撃したとき、味方リーダーのHPを2回復する
- 黒：攻撃力+2

## 絵

### 外見

黒い刀身の長剣と、剣に宿ったノア。剣は人の背丈ほどの長さで、刀身は光を吸う黒、鍔と柄は鈍い銀。ノアは20歳の人間の女性の霊で、亜麻色の長い髪を緩く編み、空色の瞳。素朴な生成りのワンピースに草色の肩掛け。全身が乳白色の光で半ば透けている。

### 情景

丘の上の地面に長剣がまっすぐ突き立ち、鍔元から乳白色の光の粒が溢れて舞い上がっている。光の中からノアの霊が現れ、剣の柄にそっと両手を添えて寄り添い、穏やかに微笑んでいる。視線は画面の手前。

### 背景

月明かりの澄んだ夜。丘の草が銀色に光り、明るい。
