# 市場の売り子

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 1 |
| 攻撃力 | 2 |
| HP | 1 |
| 投入枚数 | 3 |

## 効果

死亡時：カードを1枚引く

## 絵

### 外見

20代の女性。栗色の髪を生成りの布で包み、榛色の瞳。袖の短い麻の服に、薬草の染みがついた前掛け。指先が緑に染まっている。声が大きく、よく笑う雰囲気。

### 情景

露店の台に片手をついて身を乗り出し、もう片手で乾いた薬草の束を高く掲げて、通りの客へ大きく口を開けて呼びかけている。

### 背景

明るい昼の市。色とりどりの日除け布が頭上に重なり、露店の湯気が日差しに光っている。
