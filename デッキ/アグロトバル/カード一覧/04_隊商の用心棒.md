# 隊商の用心棒

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

召喚時：手札を1枚選んで捨てる。速攻を得る

## 絵

### 外見

30代の男性。髪は日除けの頭布で覆い、日に焼けた肌に鋭い目。砂埃のついた旅装に革の籠手。手には短い槍。無口で、動き出すと速い雰囲気。

### 情景

薬草の袋を積んだ荷車の陰から低く飛び出し、短槍を腰だめに構えて画面の手前へ突っ込んでくる。後ろ足が地面を強く蹴り、砂埃が舞っている。

### 背景

明るい昼の市の外れ。荷車が並び、乾いた日差しが砂埃を白く光らせている。
