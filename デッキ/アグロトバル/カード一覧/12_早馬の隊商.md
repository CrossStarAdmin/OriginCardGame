# 早馬の隊商

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

- 召喚時：+1/+1し、速攻を得る。その後、敵キャラクター1体に4ダメージを与える
- 選別：このカードを場に出す

## 絵

### 外見

20代の男性。髪は日除けの頭布で覆い、端が風になびいている。日に焼けた肌に明るい目。砂埃のついた軽い旅装で、鞍に薬草の袋をいくつも括りつけた栗毛の馬に乗っている。一刻も早く届けようとする、勢いのある雰囲気。

### 情景

馬が前脚を大きく蹴り出して市の門をくぐり抜け、画面の手前へ駆け込んでくる。乗り手は身を低く伏せ、手綱を握って前だけを見ている。

### 背景

明るい昼の市の門。砂埃が日差しに白く舞い上がっている。
