# 隊商の頭

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 3 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

- 貫通
- 召喚時：味方キャラクター全体を+1/+0する

## 絵

### 外見

50代の女性。髪は日除けの頭布で覆い、日に焼けた皺の深い顔に鋭い目。砂埃のついた厚手の旅装に、腰に巻いた地図入れの革筒。手には長い鞭。隊商の全員を声ひとつで動かす、豪快な雰囲気。

### 情景

荷車の荷台に片足をかけて身を乗り出し、鞭を持った腕を前へ大きく振り下ろして、隊列に前進を叫んでいる。

### 背景

明るい昼の街道。長く続く荷車の列が砂埃を上げ、乾いた日差しに光っている。
