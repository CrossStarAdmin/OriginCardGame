# 運び屋ゴルダ

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 4 |
| HP | 5 |
| 投入枚数 | 3 |

## 効果

召喚時：「薬草」を3枚手札に加える

## 絵

### 外見

運び屋のゴーレム。人ではない。石の胴と木の手足を組んだ体で、背丈は人の2倍ある。肩と背に苔が生え、背中に薬草があふれる大きな籠を二つ背負っている。顔は丸い石に穴が二つ空いただけで、穏やかな雰囲気。

### 情景

広場の石畳を重い足でしっかり踏みしめて歩きながら、太い木の腕を下へ伸ばし、籠から取った薬草の束を足元の子どもへ差し出している。

### 背景

明るい昼の市の広場。色とりどりの日除け布と人込みが、ゴルダの足元に広がっている。
