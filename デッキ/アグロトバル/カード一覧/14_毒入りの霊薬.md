# 毒入りの霊薬

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | スペル |
| コスト | 7 |
| 投入枚数 | 3 |

## 効果

- 敵リーダーに4ダメージを与える
- 選別：敵リーダーに2ダメージを与え、カードを1枚引く

## 絵

### 外見

精緻な細工の硝子の霊薬瓶。中の琥珀色の液体に、黒い澱が渦を巻いている。瓶を置く手は指先が薬草の汁で緑に染まり、擦り切れた深緑の外套の袖が見える。

### 情景

金の杯や宝箱が積まれた献上品の山の中へ、トバルの手が霊薬瓶をそっと差し込む。瓶の口から細い白い湯気が画面の上半分へ立ちのぼり、枯れた薬草の葉が一枚舞っている。

### 背景

暗い石の広間。光は霊薬瓶の中の琥珀色と、献上品の金の鈍い反射だけ。
