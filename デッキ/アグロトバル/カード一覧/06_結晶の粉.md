# 結晶の粉

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | スペル |
| コスト | 2 |
| 投入枚数 | 3 |

## 効果

キャラクター1体を選ぶ。味方キャラクターなら+2/+2し、敵キャラクターなら-2/-2する

## 絵

### 外見

石の乳鉢と、それを擦る若い男の両手。手は指先から青白く透き通りかけている。乳鉢の中には、削った結晶の青白くきらめく細かい粉。

### 情景

乳棒が乳鉢の底を強く擦り、青白くきらめく粉が渦を巻いて画面の上半分へ舞い上がる。舞った粉の向こうに、手を伸ばす人々の笑顔がぼやけて見える。

### 背景

夕暮れの広場。青白い粉のきらめきが周りの人の顔を下から照らしている。
