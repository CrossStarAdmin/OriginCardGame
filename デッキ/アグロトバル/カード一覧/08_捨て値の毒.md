# 捨て値の毒

| 項目 | 内容 |
|---|---|
| クラス | プリースト |
| 種類 | スペル |
| コスト | 3 |
| 投入枚数 | 3 |

## 効果

このターン中、薬草は回復ではなくダメージを与える

## 絵

### 外見

トバルの手と、黒ずんだ紙の薬包。手は指先が薬草の汁で緑に染まり、擦り切れた深緑の外套の袖が見える。

### 情景

トバルの指が秤の皿から薬包を弾き飛ばし、破れた包みから黒緑の粉が煙になって画面の上半分へ広がる。煙の中で白い湯気と枯れた薬草の葉が渦を巻いている。

### 背景

夜の閉じた露店。小さな灯火だけが秤と薬瓶を照らし、周りは暗い。
