# ギズモ

| 項目 | 内容 |
|---|---|
| クラス | 焔術士 |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

残火：速攻を得る

## 絵

### 外見

20代の男性。跳ねた赤茶の髪、琥珀色の瞳。継ぎ接ぎだらけの道具屋のコートを着て、腰に工具を提げている。腕に真新しい火傷。店を焼かれてなお居座る、荒っぽく人懐こい雰囲気。

### 情景

低い姿勢で駆けながら、すでに火球を灯して投げる構えに腕を振りかぶっている。

### 背景

燃え始めた町。炎が背後で上がっている。
