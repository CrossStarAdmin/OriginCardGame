# ポルカ

| 項目 | 内容 |
|---|---|
| クラス | ウィザード |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 3 |
| HP | 1 |
| 投入枚数 | 3 |

## 効果

突進
場に出たとき：自分の場にマルカがいるなら速攻を得る

## 絵

### 外見

12歳の双子の姉。ショートヘアの赤茶の髪、琥珀色の瞳。おてんばで、戦いがあるとすぐに前に出る。マルカがいると勇気が出て、より前寄りになる。マルカと対になる姿。

### 情景

両手から炎を引きながら走って跳び出す。勇気に満ちた目をしていて、画面の外にいる先生へ立ち向かおうとしている。先生は画面に描かない。

### 背景

町が平和な頃。希望にあふれている。
