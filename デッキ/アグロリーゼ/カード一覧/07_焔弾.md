# 焔弾

| 項目 | 内容 |
|---|---|
| クラス | 焔術士 |
| 種類 | スペル |
| コスト | 2 |
| 投入枚数 | 3 |

## 効果

1体に3ダメージを与える

## 絵

### 外見

リーゼが撃っている。16歳の少女で、少し傷んだポニーテールの緋色の髪、鋭い琥珀色の瞳。実用的な革の装備の上に焦げた黒と深紅のマントを羽織り、下はスカート。剥き出しの前腕に古い火傷の痕。据わった鋭い目つき。

### 情景

リーゼが片手を前へ突き出し、圧縮された白熱の炎の球を砲弾のように撃ち出す。背後の煙に衝撃波の輪が穿たれる。炎の球が画面でいちばん明るく、リーゼは撃つ側として画面に入る。

### 背景

燃え始めた町。炎が背後で上がっている。
