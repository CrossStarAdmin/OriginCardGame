# ドロテ

| 項目 | 内容 |

| クラス | 焔術士 |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 4 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

残火：+2/+0して速攻を得る

## 絵

### 外見

20代後半の女性。長身で引き締まった体つき。後ろで束ねた長い緋色の髪、琥珀色の瞳。石材を運ぶ仕事着の上に焦げた前掛け。両手と肩に火傷の痕。学舎一の秀才だった鋭さが、そのまま獰猛さに変わった雰囲気。

### 情景

上昇気流に髪をなびかせ、全体を炎に包まれた刃を構えて突進する。歩幅の後ろに炎の航跡。

### 背景

町が燃え落ちていく夜。炎だけが光っている。
