# 火口の洞守り

| 項目 | 内容 |
|---|---|
| クラス | 焔術士 |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 3 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

召喚時：敵キャラクター1体を、次の自分のターン開始時まで動けなくする

## 絵

### 外見

火山岩の重厚な鎧を全身にまとった火口の洞の番人。兜の奥は影で顔が見えない。鎧の継ぎ目から熱が漏れている。人の倍ほどの体格。

### 情景

何かを押し止めるため、巨大な玄武岩の板を岩の裂け目に嵌め込んでいる。割れ目から溶岩が光る。

### 背景

燃え始めた町。炎が背後で上がっている。
