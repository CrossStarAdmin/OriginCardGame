# 火の子

| 項目 | 内容 |
|---|---|
| クラス | 焔術士 |
| 種類 | キャラクター |
| コスト | 1 |
| 攻撃力 | 1 |
| HP | 1 |
| 投入枚数 | 3 |

## 効果

召喚時：敵ユニット1体に1ダメージを与える
このターン中、「残火状態」になる

## 絵

### 外見

生きた炎そのものでできた、子供ほどの大きさの小さな精霊。輪郭は絶えず揺らぎ、目と口だけが暗い穴になっている。人ではなく、意思を持った火。

### 情景

溶岩の流れる岩棚を跳ねるように渡りながら、野生的な笑顔で火の塊を前方へ投げつけ、火花を引いている。身をひねった動作の途中。

### 背景

火山の火口近く。溶けた岩の赤い光が下から照らす。人の営みも町も見えない。
