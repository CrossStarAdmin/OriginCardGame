# マルカ

| 項目 | 内容 |
|---|---|
| クラス | 焔術士 |
| 種類 | キャラクター |
| コスト | 1 |
| 攻撃力 | 1 |
| HP | 1 |
| 投入枚数 | 3 |

## 効果

テンションリンク：手札からポルカを1体出す
ターン終了時：場にポルカがいるなら+0/+1して守護を持つ

## 絵

### 外見

12歳の双子の妹。ツインテールの赤茶の髪、琥珀色の瞳。まだ学舎の子供なので、肌は綺麗で火傷の痕は無い。慎重で引っ込み思案だが、いざというときは動く。ポルカと対になる姿。

### 情景

焦げた重い鉄の鍋蓋を盾のように両手で抱え、不安そうに授業を受けている。誰とも戦っておらず、武器も持たない。不安そうに眉を寄せながらも、その場から離れずに踏みとどまっている。

### 背景

町が平和な頃。希望にあふれている。
