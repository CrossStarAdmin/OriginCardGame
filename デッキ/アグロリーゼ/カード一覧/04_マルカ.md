# マルカ

| 項目 | 内容 |
|---|---|
| クラス | 焔術士 |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 1 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

- 守護
- テンションリンク：手札からポルカを1体出す

## 絵

### 外見

双子の使い魔の姉。人の膝ほどの背丈で、炭のように黒い毛並みに熾火の橙の筋が走る獣。丸くどっしりした体つきと、落ち着いた金の目。ポルカと対になる姿。

### 情景

焦げた重い鉄の鍋蓋を盾に構え、見えない誰かの前に立ちはだかる。食いしばった顎。

### 背景

まだ人が住んでいる頃の町。明るい火の色。
