# 裏切のグラーク

| 項目 | 内容 |
| --- | --- |
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 6 |
| HP | 8 |
| 投入枚数 | 3 |
| 種族タグ | 六罪 |

## 効果

- 突進
- 召喚時：味方全体に3ダメージを与える

## 絵

### 外見

人ではない魔族。人の3倍の背丈がある。異形。赤色。鬼のようないかつい見た目。鉄の鎧を装備している。顔の下半分を鉄の顎が覆い、小さな黒い目が光る。顔は顎以外に鉄の鎧は装備していない。太い両腕の先は鉄の塊のような拳。拳は人を潰せるくらいでかい。人を見下ろして愉しんでいる雰囲気で、幼さや愛嬌は一切無い。

### 情景

砦の城壁の上に腰を下ろし、片膝に肘をついて下の門を見下ろしている。門からは何本もの縄が垂れて風に揺れている。黄色い目が細まり、鉄の顎の奥で笑っている。

### 背景

厚い曇天。色が失われ、砦全体に重い影が落ちている。
