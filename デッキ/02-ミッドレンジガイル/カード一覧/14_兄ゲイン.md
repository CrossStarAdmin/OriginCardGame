# 兄ゲイン

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 6 |
| 攻撃力 | 5 |
| HP | 5 |
| 投入枚数 | 3 |

## 効果

- 場にいる限り、リーダーの受けるダメージを-3する
- 死亡時：デッキから武器カードを1枚選んでリーダーに装備する

## 絵

### 外見

28歳の男性。灰褐色の短い髪を後ろへ撫でつけ、鋼色の瞳。日に焼けた肌に無精髭。砦の隊長の鉄鎧に、色褪せた赤いマント。頬に古い切り傷の痕。肩が落ち、目の奥が揺れている雰囲気。

### 情景

城壁の上で長剣を抜き、切っ先を画面の手前へまっすぐ向けている。構えは崩れていないが、視線だけが横の高いところへ逸れている。

### 背景

厚い曇天。色が失われ、背後の高い城壁に巨大な影が落ちている。
