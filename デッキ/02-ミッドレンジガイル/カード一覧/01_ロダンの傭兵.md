# ロダンの傭兵

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 1 |
| 攻撃力 | 1 |
| HP | 1 |
| 投入枚数 | 3 |

## 効果

召喚時：1体に1ダメージを与える

## 絵

### 外見

20代半ばの男性。無造作に伸ばした灰褐色の髪、鋼色の瞳。日に焼けた肌。継ぎはぎの革鎧に、刃の欠けた片手斧。腕と首に古い切り傷の痕。荒っぽく笑う、場慣れした雰囲気。

### 情景

荒れ地の岩に片足をかけ、口で包帯の端をくわえて自分の腕の傷をきつく締めている。もう片方の手で片手斧を肩に担ぎ、目線は画面の奥の砦に向いている。

### 背景

乾いた昼の日光。砂埃が薄く舞う、明るい荒れ地。
