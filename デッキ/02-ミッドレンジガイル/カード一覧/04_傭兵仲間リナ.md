# 傭兵仲間リナ

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

- 召喚時：敵キャラクター全体に1ダメージを与える
- 「不屈状態」なら代わりに敵キャラクター全体に2ダメージを与える

## フレーバー

「あんたなら、ロダンの希望になれる。……私、人を見る目はあるのよっ！」

## 絵

### 外見

23歳の女性。灰褐色の髪を後ろで一つに高く束ね、鋼色の瞳。日に焼けた肌。軽い革鎧に赤いスカーフを首に巻き、腰に短剣を差している。頬に小さな古い切り傷の痕。口元に不敵な笑みを浮かべた、快活な雰囲気。

### 情景

荒れ地を駆け込みながら、右手の長剣を横に振り抜いている。左手では小さな砥石を画面の外の仲間へ放り投げていて、視線もそちらへ向いている。

### 背景

乾いた昼の日光。蹴り上げた砂埃が明るく光っている。
