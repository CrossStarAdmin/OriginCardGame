# 一騎打ち

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | スペル |
| コスト | 3 |
| 投入枚数 | 3 |

## 効果

- 味方リーダーに2ダメージを与える、敵キャラクター1体を破壊する
- 「不屈状態」なら味方リーダーへのダメージを0にする

## フレーバー

罪を植えず、力で来た相手を、力で押し返した。

## 絵

### 外見

ガイルとグラークがぶつかっている。ガイルは22歳の男性で、無造作に伸ばした灰褐色の髪、鋼色の瞳。黒く煤けた継ぎ接ぎの革鎧に鉄の肩当て、裾の裂けた赤いマントと赤い腰布。両腕と首と頬に無数の古い切り傷の痕。右の前腕に血の滲んだ包帯。グラークは人ではない魔族で、ガイルの2倍の背丈がある。鉄錆色の分厚い皮膚が鎧の板のように重なり、顔の下半分を鉄の顎が覆い、小さな黄色い目が光る。

### 情景

ガイルが刃の欠けた片手斧を振り上げ、振り下ろされたグラークの鉄の腕を真正面から受け止めている。刃と腕がぶつかった一点から白橙の火花が画面の上半分へ弾ける。ガイルは両足で地面を削りながら押し返している。

### 背景

沈む夕日の赤い逆光。二人の輪郭が赤く縁取られている。
