# ドヴァルの遺作

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | 武器 |
| コスト | 7 |
| 攻撃力 | 3 |
| 投入枚数 | 2 |

## 効果

- 装備時：1体に4ダメージを与える

## フレーバー

吊るされる前の晩、ドヴァルは頼まれてもいない斧を一挺だけ打っていた。

## 絵

### 外見

黒みを帯びた鋼の、大ぶりな片手斧。三日月形の分厚い刃に、槌で打った跡が細かく残っている。柄は鉄の帯で補強した樫で、握りには色褪せた赤い布が固く巻かれている。

### 情景

荒れた岩場に、この斧が刃を深く食い込ませて、やや斜めに傾いて刺さっている。柄が画面の上へ向かって斜めに伸び、斧が画面の大部分を占める。人物は描かない。

### 背景

沈む夕日の赤い逆光。地平線近くに大きな夕日、赤く焼けた雲が空いっぱいに広がる。遠くに岩山の稜線。斧の輪郭が赤く光っている。
