# 型の写本

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | スペル |
| コスト | 3 |
| 投入枚数 | 3 |

## 効果

自分の墓地からコスト2以下のカードを2枚選び、手札に加える

## 絵

### 外見

老師ロウとシュリ。ロウは70歳の男性で、白くなった髪を後ろで結い、深い緑の瞳、白い長い眉。日に焼けた皺の深い肌。擦り切れた生成りの道着に黒い帯、素足。シュリは20歳の女性で、長い焦げ茶の髪を後ろで高く一つに結い、深い緑の瞳。日に焼けた肌。生成りの道着に黒い帯、両拳にさらしを巻き、素足。

### 情景

稽古場の縁側で、ロウが紐で固く結ばれた古い巻物を両手でシュリに差し出し、シュリが片膝をついて両手で受け取ろうとしている。二人の間を朝の風が吹き抜け、山霧が流れている。視線はロウがシュリへ、シュリが巻物へ。

### 背景

澄んだ朝の山。朝日が縁側を明るく照らし、柔らかな光が差し込んでいる。
