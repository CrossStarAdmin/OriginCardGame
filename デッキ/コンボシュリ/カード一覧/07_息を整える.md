# 息を整える

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | スペル |
| コスト | 2 |
| 投入枚数 | 3 |

## 効果

味方リーダーのHPを3回復し、カードを1枚引く

## 絵

### 外見

シュリが呼吸を整えている。20歳の女性で、長い焦げ茶の髪を後ろで高く一つに結い、深い緑の瞳。日に焼けた肌。生成りの道着に黒い帯、両拳にさらしを巻き、素足。

### 情景

シュリが崖の突き出た平らな岩の上に素足で立ち、両手を下腹の前でゆっくり下ろしながら目を閉じて深く息を吐いている。吐く息に合わせて、周りの山霧が体を中心に大きな渦を巻いている。

### 背景

澄んだ朝の山。朝日が霧を白く光らせ、遠くの峰まで明るく見渡せる。
