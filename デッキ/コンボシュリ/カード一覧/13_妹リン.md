# 妹リン

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 7 |
| HP | 7 |
| 投入枚数 | 3 |

## 効果

- 速攻
- 召喚時：味方リーダーに3ダメージを与える
- ターン終了時：このキャラクターを破壊する

## 絵

### 外見

18歳の女性。肩までの焦げ茶の短い髪が乱れている。深い緑の瞳。日に焼けた肌の下を、暗い赤の筋が脈打って全身に走っている。破れた生成りの道着に黒い帯、両拳のさらしは裂けてほどけかけ、素足。力に呑まれかけた、張りつめた顔つき。

### 情景

リンが壊れた家の瓦礫を蹴って前へ跳び、右の拳を大きく振りかぶって正面へ殴りかかっている。拳の周りで空気が荒く弾け、足元の瓦礫が砕けて舞っている。視線は正面、歯を食いしばっている。

### 背景

夕闇に沈んだ里。厚い雲が低く垂れ、崩れた家の影が重く暗い。
