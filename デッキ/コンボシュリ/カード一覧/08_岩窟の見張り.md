# 岩窟の見張り

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 1 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

召喚時：敵キャラクター1体に5ダメージを与える

## 絵

### 外見

35歳の女性。焦げ茶の髪を後ろで固くまとめている。深い緑の瞳。日に焼けた肌で、腕と脚の太い頑丈な体。生成りの道着に黒い帯、両拳にさらしを巻き、素足。無口で、動じない顔つき。

### 情景

山頂の岩窟の入口の真ん中で、両足を大きく開いて岩の地面に踏ん張り、両の拳を胸の前に構えて立ちふさがっている。視線は岩窟へ登ってくる山道の先、正面。

### 背景

澄んだ朝の山頂。朝日が岩窟の入口を明るく照らし、足元を山霧が流れている。
