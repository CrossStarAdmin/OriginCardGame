# 組み手の兄弟子

| クラス | ウォーリア |
| 種類 | キャラクター |
| コスト | 2 |
| 攻撃力 | 2 |
| HP | 3 |
| 投入枚数 | 3 |

## 効果

連携1：守護を得る

## 絵

### 外見

25歳の男性。後ろで短く束ねた焦げ茶の髪、深い緑の瞳。日に焼けた肌で、肩幅の広いがっしりした体。生成りの道着に黒い帯、両拳にさらしを巻き、素足。落ち着いた、面倒見のよい顔つき。

### 情景

組み手の最中、正面から来た拳を右の掌で横へ払い、左の拳を胸の前に引いて構えている。払った掌のところで空気が透明な輪になって弾けている。両足は石畳にしっかり着き、視線は正面の相手へ。

### 背景

澄んだ朝の山の稽古場。朝日で明るく、足元に砂塵が薄く舞っている。
