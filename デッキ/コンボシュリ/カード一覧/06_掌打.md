# 掌打

| 項目 | 内容 |
|---|---|
| クラス | ウォーリア |
| 種類 | スペル |
| コスト | 2 |
| 投入枚数 | 3 |

## 効果

敵キャラクター1体に4ダメージを与える

## 絵

### 外見

シュリが掌底を打っている。20歳の女性で、長い焦げ茶の髪を後ろで高く一つに結い、深い緑の瞳。日に焼けた肌。生成りの道着に黒い帯、両拳にさらしを巻き、素足。

### 情景

シュリが深く腰を落とし、人の背丈ほどある大岩に右の掌底を打ち込んでいる。掌の当たった一点から岩に亀裂が走り、空気が大きな透明な輪になって弾け、砂塵が画面の上半分へ吹き上がっている。視線は掌の先の岩。

### 背景

澄んだ朝の山。朝日が岩場を明るく照らし、谷に山霧が溜まっている。
