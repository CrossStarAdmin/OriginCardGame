# コンボシュリ

守護と除去で耐えながら軽いカードを手札に溜め、10ターン目に「老師ロウ」でMPを戻しつつ「連携」を積み、奥義「拳で届かせる」を続けて撃って決めるウォーリアのコンボ。

## 勝ち筋と負け筋

- **勝ち筋**：10ターン目前後、「妹リン」「渇望のガドル」で削った敵リーダーに、ロウでMPを戻しながら連携を積んだ「拳で届かせる」を2〜3枚撃つ
- **負け筋**：序盤に顔を削る手段が無く、守護は門下生・兄弟子・ロウ・ガドルだけ。横並びと速攻に10ターン目より前に抜かれるか、回復で敵リーダーのHPを戻されると届かない
- **とどめ**：1〜2コストを続けて使い、練気とロウで連携とMPを伸ばしてからの「拳で届かせる」連打。足りないぶんは「妹リン」の速攻7点

## デッキ固有能力

- **連携**：このターンに、自分がこのカードより前に使ったカードの枚数。パワースキル「練気」を使うと、そのターン中+1される
  - ex) `連携3：MPを4回復する` → このターンにこのカードより前にカードを3枚以上使っていたなら、MPを4回復する
  - ex) `敵1体に、連携の数+2ダメージを与える` → このターンに前に4枚使っていたなら、6ダメージを与える
- キャラクター・スペルのどちらを使っても1枚と数える。判定は手札から使ったときに1回だけ行う

## 回し方

### 序盤（1〜3ターン）
「ガンザの門下生」の守護と「牽制の拳」「掌打」で小型を止め、「岩窟の見張り」の5ダメージで中型を落とす。「朝駆け」「弟弟子カイ」は使っても手札が減らないので、材料を切らさずに守れる。

### 中盤（4〜6ターン）
「渇望のガドル」の守護で盤面を支え、攻撃されるたびに敵リーダーを1点削る。横並びは「旋風脚」で流す。連携2なら全体4ダメージになる。「妹リン」は速攻で顔に7点を入れ、自分も3点受けてターン終了時に破壊される。「息を整える」でHPと手札を保ち、空いたMPでパワーを3にしておく。

### 終盤（7ターン〜）
10ターン目、たとえば「門下生・牽制の拳・カイ → 練気 → 老師ロウ → 拳で届かせる → 拳で届かせる」と使う。ロウは連携4でMPを4戻すので、奥義は連携5で7点、連携6で8点、合わせて15点になる。材料が足りなければ「型の写本」で墓地の1〜2コストを2枚拾い直す。

### 仕掛けの回り方
連携は「ガンザの門下生」「牽制の拳」「組み手の兄弟子」「拳で届かせる」「老師ロウ」「旋風脚」の16枚に乗る。軸はロウで、**連携3に届く前に出すとMPが戻らず、4コストの1/2守護になる。** 決める日に1〜2コストが手札に無いと連携が伸びず、奥義は1枚あたり数点で止まる。

### 有利不利
- **有利**：ランプ、ミッドレンジ。見張りと掌打で大型も落とせて、奥義は盤面に関係なく敵リーダーに届く
- **不利**：アグロ。序盤の打点が無く、守護も薄いので、横並びと速攻に10ターン目まで耐えきれない
- **五分**：コントロール。除去は奥義に触れないが、回復で敵リーダーのHPを戻されるほど必要な連携が増える

### 素点の補足
- 「ガンザの門下生」は1コスト1/1守護（目安2.5に対し2）。連携2で1/3、連携4で2/4になる
- 「掌打」は2コストで4ダメージ（目安3コスト）
- 「岩窟の見張り」は3コスト1/4に、召喚時の5ダメージ（スペルなら4コスト）が付く
- 「老師ロウ」は4コスト1/2守護（目安8.5に対し3）。連携3でMPを4戻し、実質0コストで連携を+1する
- 「旋風脚」は全体2ダメージで4コスト（目安3）。連携2で全体4ダメージ（目安5）になる
- 「妹リン」は5コスト7/7速攻（目安9に対し14）。召喚時に味方リーダーへ3ダメージを与え、ターン終了時に破壊される
- 「渇望のガドル」は6コスト4/9守護（目安12.5に対し13）に、攻撃されるたびの1ダメージが付く
- 顔へ直接飛ぶダメージは、奥義（連携0で2点、決めるターンで7〜9点）とガドルの1点。決めるターンに奥義を2〜3枚撃つと15〜25点になり、バーンの目安15を超える。序盤に顔を削る手段を持たせないことで釣り合いを取っている

## 見た目の共通ルール

1. **光源は山の朝の光。** 基調は岩肌の灰、山霧の白、道着の生成り。差し色に朝焼けの茜色。魔法の光で画面を照らさない。
2. **力の見た目は拳の衝撃で統一する。** 拳や蹴りが当たるところには、空気が透明な輪になって弾け、霧と砂塵が吹き散る。魔法陣・記号・炎・光のオーラは使わない。ガンザの人間は武器を持たず、素手で戦う。ガドルの術で得た力だけは、肌の下を脈打つ暗い赤の筋として描く。
3. **リンの暴走の前後で空を変える。** 暴走の前、里の日常と稽古は、澄んだ朝の山を朝日で明るく描く。暴走のあと（妹リン・旋風脚・渇望のガドル）は、厚い曇天か夕闇で色を失わせ、崩れた家や岩窟の影を重く落とす。シュリの奥義「拳で届かせる」とシュリ本人は、雲を割って差し込む朝日で明るく描く。
