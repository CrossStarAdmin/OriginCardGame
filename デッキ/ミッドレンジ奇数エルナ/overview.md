# ミッドレンジ奇数エルナ

デッキのトップを利用して戦う。
「ルック：奇数」で格上のスタッツと追加効果を絞り出し、盤面を取り続ける職業「占い師」のミッドレンジ。

| 項目 | 内容 |
|---|---|
| リーダー | エルナ |
| クラス | 占い師 |
| アーキタイプ | ミッドレンジ |
| 舞台 | 星の町 オルレア |
| 合計枚数 | 40 |

## 勝ち筋と負け筋

- **勝ち筋**：奇数がめくれ続けるかぎりコスト以上の効果を獲得することができ、盤面有利をそのまま押し切る
- **負け筋**：偶数だとコスト以下の効果しか出ない。偶数が続くと有利な戦いも不利になっていく。回復が薄く、一度崩れると戻せない。
- **とどめ**：墓地の「相棒ヴァルザ」から速攻と貫通を得た「識りすぎたヴァルザ」

## リーダー

**エルナ** ／ テンションスキル：**星読み**

> デッキの上から3枚を見て、その中から1枚を手札に加える。残りの2枚を好きな順番でデッキの上か下に置く。

詳細は [00_エルナ](カード一覧/00_エルナ.md)

## 用語

### デッキ固有能力

- **ルック**：デッキの上1枚を見る。それが該当カードなら、続く効果が発動する
  - ex) `ルック：奇数：カードを1枚引く` → デッキの上1枚を見て、それが奇数コストならカードを1枚引く

### このデッキで主に利用する能力

- **守護**：相手はこのキャラクターを先に攻撃しなければならない
- **突進**：出したターンから敵キャラクターを攻撃できる
- **貫通**：キャラクターを攻撃したとき、そのキャラクターの残りHPを超えたぶんのダメージをリーダーに与える
- **おうえん**：召喚時にテンションを+1する
- **テンションリンク**：自分のテンションが上がったときに発動する
- **場**：敵味方すべてのキャラクター（リーダーは含まない）

## 回し方

### 序盤（1〜3ターン）
「オルレアの民」「使い魔サキュ」「凶兆のまたたき」「先を読む力」で場に触りつつ、サキュと先を読む力のルックでトップを整える。

### 中盤（4〜6ターン）
「夜番の観測者」「姉マイア」「相棒ヴァルザ」など3〜4コストを毎ターン展開し、奇数がめくれれば格上のスタッツで盤面を取る。「守り役オルド」と「深読み」でトップを操作し、奇数を続けやすくする。

### 終盤（7ターン〜）
墓地に「相棒ヴァルザ」を用意してから「識りすぎたヴァルザ」を速攻で通し、「傲慢のノクス」「天文台の護り」で盤面と本体を詰める。

### 仕掛けの回り方
「ルック：奇数」の成否はデッキの偶奇構成に依存する。奇数コスト中心に組んでいるため基本は成功しやすく、「守り役オルド」「先を読む力」「写し手ヨナ」でトップを能動的に置き替えられる。「傲慢のノクス」だけは偶数だと自分に牙が向く。

### 有利不利
- **有利**：横並びのアグロ。平均スタッツ勝ちで受けきれる
- **不利**：全体除去と回復を持つコントロール。単体の押し込み力が細い
- **五分**：同格のミッドレンジ。先に盤面差を作った側が取る

## 見た目の共通ルール

1. **光源は星光。** 基調は深い藍と黒、差し色に淡い金と冷たい菫色。夜空をテーマ。明るい場面では星の光そのものを強く輝かせ、その光で画面を照らす。暖色はランプの小さな火だけに許す。炎や日光で明るくしない。
2. **力の見た目は星座の記号で統一する。** 力が働いているところには、淡く光る星座の記号が必ず出る。魔法陣や十字などの他の記号は使わない。味方と日常の力は淡い金、凶兆と闇落ち後の力は冷たい菫色。観測の道具（星時計・望遠鏡・アストロラーベ・星図）はすべて真鍮。
3. **ヴァルザの闇落ちで空気を変える。** 物語のはじめ、いつもの日常を表現したいときは明るい、素敵な夜空にする。ロマンチックな情景にする。ヴァルザが闇落ちし、町が暗くなったシーンを表現するときは暗く、よどんだ空気にする。
4. **目で描き分ける。** 闇落ち後のヴァルザ系は瞼が無く、目を閉じない。ほかのカードは「見上げる」「伏せる」で対比する。
