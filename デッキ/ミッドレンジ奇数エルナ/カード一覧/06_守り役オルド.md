# 守り役オルド

| 項目 | 内容 |
|---|---|
| クラス | ウィザード |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

- 守護
- 召喚時：デッキの上から5枚を見て、好きな順番でデッキの上か下に置く

## フレーバー

「天文台を守るのだって、立派な仕事だ」彼は誇らしげに語る。

## 絵

### 外見

40代の男性。少し白髪交じりの黒色の短い髪を持つ。琥珀色の瞳。星図を打ち出した真鍮と鋼の鎧をまとった、恰幅の良い中年兵士。自分の背丈ほどある大きなタワーシールドを持ち、傷の多い太い手をしている。何があっても動じない、静かで頑固な雰囲気。

### 情景

天文台へ続く石段の下に立ちはだかり、タワーシールドを地に据えて両手で支える。こちらを正面から見据え、微動だにしない。誰も通さないという構え。

### 背景

明るい星夜。
