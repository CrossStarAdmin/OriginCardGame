# 天文台の護り

| 項目 | 内容 |
|---|---|
| クラス | ウィザード |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 4 |
| HP | 5 |
| 投入枚数 | 3 |

## 効果

- 守護
- 召喚時：ルック：奇数：味方リーダーのHPを4回復する

## 絵

### 外見

真鍮と石でできた巨大な鎧の守護者。人の3倍ほどの背丈がある。顔が無く、頭部はのっぺりした石の面。胸に嵌め込まれた真鍮のアストロラーベの環がゆっくり回る。意思を持たない機構であり、人でも生き物でもない。

### 情景

天文台の戸口を塞いで両足を踏ん張り、こちらへ立ちはだかっている。

### 背景

明るい星夜。
