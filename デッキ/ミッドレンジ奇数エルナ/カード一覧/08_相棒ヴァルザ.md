# 相棒ヴァルザ

| 項目 | 内容 |
|---|---|
| クラス | ウィザード |
| 種類 | キャラクター |
| コスト | 4 |
| 攻撃力 | 4 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

召喚時：ルック：奇数：敵キャラクター１体に3ダメージ
死亡時：デッキから「識りすぎたヴァルザ」を手札に加え、その後デッキをシャッフルする

## 絵

### 外見

20代前半の美青年。艶のある長い黒髪、鋭い琥珀色の瞳を持つ、黒と深紫の衣装に金の刺繍を施し、紫色の宝石や繊細な装飾品を身につけている。知的で余裕のある微笑みを浮かべた、妖艶かつミステリアスな雰囲気の占星術師。

### 情景

雑然とした天文台の机に身を乗り出し、片手を開いた星図に置いたまま、肩越しに振り返って笑う。卓上のランプと夜空の星がヴァルザを照らし、

### 背景

まだ人間で、まだ目を閉じられる。闇落ち前なので明るい。「識りすぎたヴァルザ」と同一人物と分かる顔で描く。
