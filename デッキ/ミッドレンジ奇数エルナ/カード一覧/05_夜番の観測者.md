# 夜番の観測者

| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 3 |

## 効果

召喚時：ルック：奇数：+1/+1する

## 絵

### 外見

20代後半の男性。短く整えた黒髪、琥珀色の瞳。天文台の夜番で、防寒の効いた厚手の藍色の外套を羽織り、肩に長い真鍮の望遠鏡を担いでいる。生真面目で口の堅い、落ち着いた雰囲気。

### 情景

天文台のバルコニーに立ち、空を掃くように見渡している。足元に真鍮のランタンが置かれている。

### 背景

明るい星夜。
