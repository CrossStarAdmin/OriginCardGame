# 写し手ヨナ

| 項目 | 内容 |
|---|---|
| クラス | 占い師 |
| 種類 | キャラクター |
| コスト | 5 |
| 攻撃力 | 2 |
| HP | 2 |
| 投入枚数 | 3 |

## 効果

- 召喚時：墓地から4コスト以下のキャラクターを1体復活させる
- ルック：奇数：さらに1コスト以下のキャラクターを1体復活させる

## 絵

### 外見

10代後半の少女。肩までの黒髪、琥珀色の瞳。簡素な藍色の仕事着を着て、羽ペンを持ち、指がインクで染まっている。気弱で、疲れの見える伏し目がちな雰囲気。

### 情景

宙に浮かぶ紙に囲まれ、空の星座を羊皮紙へ写し取る。紙面から薄い人影が立ち上がる。周りの紙はほとんど白紙。

### 背景

暗くよどんだ夜。
