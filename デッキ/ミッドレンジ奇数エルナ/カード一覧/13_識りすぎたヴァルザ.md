# 識りすぎたヴァルザ

| 項目 | 内容 |
|---|---|
| クラス | 占い師 |
| 種類 | キャラクター |
| コスト | 7 |
| 攻撃力 | 8 |
| HP | 6 |
| 投入枚数 | 3 |

## 効果

- 召喚時：墓地に「相棒ヴァルザ」があるなら速攻を得る
- ルック：奇数：貫通を得る

## 絵

### 外見

「相棒ヴァルザ」のなれのはて。20代前半の美青年だった面影を残したまま、巨大な結晶と融合し、かろうじて人の形を保つ。艶のある長い黒髪と鋭い琥珀色の瞳、黒と深紫の衣装は残っているが、**瞼を失った目は二度と閉じない。**四肢は結晶へ伸び広がった異形の体になり、今にも襲い掛かりそうな見た目をしている。

### 情景

天文台の地下、水に満ちた結晶の間に浮かび、無数の星座の記号が体から空へ流れ出す。

### 背景

デッキで最も暗い1枚で、彼自身が画面の唯一の光源。
