# 傲慢のノクス

| 項目 | 内容 |
|---|---|
| クラス | ウィザード |
| 種類 | キャラクター |
| コスト | 8 |
| 攻撃力 | 5 |
| HP | 5 |
| 投入枚数 | 2 |

## 効果

- ルック：奇数：敵全体に4ダメージを与える
- ルック：偶数：味方全体に4ダメージを与える

## フレーバー

天文台に本を一冊置いていった。それだけで帰った。

## 絵

### 外見

人より頭ひとつ背の高い、細身の魔族。顔立ちは整った青年のものだが、瞳孔の無い菫色の目と、血の気の無い灰白色の肌をしている。頭には王冠のように立ち上がる銀の角。指は異様に長く、爪は黒い。立襟の菫色のコートに金の刺繍をまとった優雅な装い。口元は丁重に微笑んでいるが、目には明確な侮蔑がある。相手を格下と見なして見下ろす、礼儀正しさそのものが恐ろしい存在。幼さや愛嬌は一切無く、骸骨や獣の顔にもしない。

### 情景

天文台の丸い銅屋根のてっぺんに立っている。ドームの曲面が彼の足元に広がり、片足を頂点にかけて体重を預け、コートの裾が屋根に触れている。眼下にはオルレアの町の灯りが小さく見え、彼が高い場所にいることが分かる。掌の上で本を燃え上がらせ、星座が彼の思うままに並び替わっていく。こちらへ視線を落としている。膝から上を大きく捉え、足元のドームまで画面に入れる。画面いっぱいに描き、周囲に余白を作らない。

### 背景

暗いが、彼の周りだけ空が整っている。
