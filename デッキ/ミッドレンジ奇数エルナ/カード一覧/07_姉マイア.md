# 姉マイア

| 項目 | 内容 |
|---|---|
| クラス | 占い師 |
| 種類 | キャラクター |
| コスト | 3 |
| 攻撃力 | 2 |
| HP | 4 |
| 投入枚数 | 3 |

## 効果

- おうえん
- テンションリンク：ルック：奇数：場のキャラクターすべてに1ダメージを与える

## 絵

### 外見

20代後半の女性。艶のある長い黒髪、琥珀色の瞳。エルナによく似た顔立ちだが、より朗らかで温かい表情をしている。淡い金と白の薄い衣をまとった踊り子の身軽な装い。手には何も持たず、身ひとつで踊る。

### 情景

踊りの動作の途中で両腕を掲げ、流星が降り注ぐ。顔は空ではなく正面を向いている。

### 背景

明るくロマンチックな星夜。
