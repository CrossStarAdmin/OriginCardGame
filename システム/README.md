# システム

**複数のスキルが共通で使うコード。**どのスキルにも属さない。

スキル同士が直接依存すると、片方を消したり動かしたりしたときにもう片方が壊れる。
共通部分をここに置いて、**各スキルはここだけを見る**。

## 中身

| ファイル | 役割 | 読むもの |
|---|---|---|
| `decks.js` | デッキとカードを読む | `デッキ/<デッキ名>/overview.md` と `カード一覧/*.md` |
| `artrules.js` | 絵の全体ルールを読む | `イラスト/共通ルール.md` |
| `prompt.js` | イラストのプロンプトを組み立てる | 上の2つ |
| `frame.js` | カード枠に関わる値（生成する縦横比） | ─ |

## 使っているスキル

| スキル | 使うもの |
|---|---|
| `generating-card-art` | 全部。プロンプトを組み立ててから画像APIへ送る |
| `showing-card-prompt` | `decks.js` `prompt.js` `frame.js`。組み立てた文面を表示するだけ |

**どちらのスキルも、相手のスキルを知らない。**

## 直すときの注意

- **プロンプトの文面はここには無い。** `イラスト/共通ルール.md` と `デッキ/` のmdにある。ここにあるのは読み方と組み立て方だけ
- **`prompt.js` を変えると、API生成と手動プロンプトの両方が同時に変わる。** それが狙いで、片方だけ変わると手で作った絵とAPIの絵が食い違う
- パスは `__dirname` 起点で解決している。どのディレクトリから実行しても同じ場所を指す
- 外部パッケージは使わない（Node標準のみ）
