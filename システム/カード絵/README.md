# カード絵

イラストのプロンプトを組み立てる共有コア。API生成と手動プロンプトの両方がここを使う。

## 中身

| ファイル | 役割 | 読むもの |
|---|---|---|
| `artrules.js` | 絵の全体ルールを読む | `イラスト/共通ルール.md` |
| `prompt.js` | イラストのプロンプトを組み立てる | `artrules.js` と、呼び出し側が渡すカード情報 |
| `frame.js` | カード枠に関わる値（生成する縦横比） | ─ |

デッキとカードのmdは `../デッキ読み込み/decks.js` で読み、呼び出し側から `prompt.js` に渡す。

## 使っているスキル

| スキル | 使うもの |
|---|---|
| `generating-card-art` | 全部。プロンプトを組み立ててから画像APIへ送る |
| `showing-card-prompt` | `prompt.js` `frame.js`。組み立てた文面を表示するだけ |
| `importing-card-art` | `prompt.js` `frame.js`。外部ツールで作った絵に .json を付ける |

**どのスキルも、ほかのスキルを知らない。**

## 直すときの注意

- **プロンプトの文面はここには無い。** `イラスト/共通ルール.md` と `デッキ/` のmdにある。ここにあるのは読み方と組み立て方だけ
- **`prompt.js` を変えると、API生成と手動プロンプトの両方が同時に変わる。** それが狙いで、片方だけ変わると手で作った絵とAPIの絵が食い違う
