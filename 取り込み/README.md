# 取り込み

**外部ツールで作ったカードイラストを、ここに置く。**

ChatGPT などで生成した画像をダウンロードして、このフォルダに入れるだけ。
あとは取り込みコマンドが、置き場の移動と `.json` の作成をやる。

## 置き方

**ファイル名をカード名と同じにする。**拡張子は `.png`。

```
取り込み/
├─ 双子の星占いエマ&エリ.png
├─ マルカ.png
└─ ドロテ.png
```

カード名は `デッキ/<デッキ名>/カード一覧/*.md` の見出し（`# カード名`）と一致させる。
どのデッキのカードかは、コマンド側が探すので指定しなくてよい。

## 取り込む

```bash
node .claude/skills/importing-card-art/import.js
```

- `イラスト/<デッキ名>/<カード名>.png` へ移す
- 同じ場所に `.json` を作る（カード情報と、そのカードのプロンプト）
- このフォルダは空になる

そのあとカード枠と合成する。

```powershell
powershell -ExecutionPolicy Bypass -File "カードフレーム/tools/compose.ps1" -Deck "<デッキ名>" -Force
```

## 注意

- **PNGだけ。** それ以外の形式は取り込まずに残る
- **同名の画像が既にあれば差し替える。** 採用済みの絵を消したくないなら、先に確認する
- このフォルダの中身はgit管理しない（作業用の一時置き場）
