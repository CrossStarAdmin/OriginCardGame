# ルール解釈の記録

カードテキストと `ルール/` だけでは一意に決まらなかった箇所と、その決定。
**シミュレーターはここに書いた通りに実装されている。**

新しく解釈が必要になったら、ユーザーに確認したうえでこの表に追記する。
解釈を変えたら `sim/effects.js` も直し、変更日を書く。

## 全体に効くもの

### 単体ダメージ呪文の対象（2026-08-24）

**決定：メラ／メラミ／メラゾーマ／ベルゼバブ／紅蓮の火球の「Nダメージを与える」は、敵1体（ユニットまたはリーダー）を選ぶ。**

`ルール/06_キーワード能力.md` の「対象が書かれていない効果は敵味方すべてが対象になる」を字義通り適用すると、
メラゾーマが全体5ダメージになり、デッキの設計意図（「盤面除去と顔へのバーンを兼ねる」）と合わないため。

> この解釈を変えると数字が大きく動く。変えるなら再計測が必要。

### 種族タグ「冒険者」の割り当て（2026-08-24）

**決定：ククールの人型カード（イザヤール／クリフト／ラヴィエル／プリン／マルチェロ／レティス）に付与する。**

`デッキ/*.md` に種族タグの記載が無いため。ラヴィエルの「3コスト以下の冒険者」サーチは
実質イザヤール固定になる。デッキファイルにタグを明記すれば、この仮定は不要になる。

### 効果で場に出したユニットの召喚時（2026-08-24）

**決定：効果で「出す」ものは召喚時を発動する（`ルール/03`「場に出た直後に発動する」に従う）。
ただしコピーを生むカードだけは例外にする。**

## カード個別

| カード | 曖昧だった点 | 決定 |
|---|---|---|
| **ベビーマジシャン** | スペルブースト1／2 の意味 | 墓地のスペルが1枚以上で1ダメージ、2枚以上でさらに1ダメージ（最大2）の**閾値方式** |
| **わかめ王子** | コピーがまた召喚時を発動するか | **しない**。デッキトップが変わらないため無限ループになる |
| **リトルライバーン** | 「リーダーが回復する度」はどちらのリーダーか | **自分のリーダー**。実際にHPが増えたときだけ誘発（満タンでは誘発しない） |
| **マーニャ** | テンションリンクの「場のユニット」の範囲 | **敵味方の全ユニット**。自分のユニットにも1ダメージが入る |
| **キングレオ** | 偶数時の「味方全体」にリーダーを含むか | **含む**。味方リーダーも4ダメージを受ける |
| **アルカナバースト** | ルックとドローの順番 | **ルックが先**。その結果でダメージ量（2 or 6）が決まり、そのあとドロー |
| **さまようたましい** | 「2ダメージを受ける」の対象 | **自分自身**。場に出た瞬間に 2/1 になる |
| **まほうつかい** | 複数体出したときの割引の重ね方 | 次に使うスペル1枚に**まとめて適用**し、使ったら0に戻る |
| **マージマタンゴ** | 「次のターン開始まで」の起点 | `ルール/07` に従い**効果の持ち主の次の開始フェイズ**まで。相手は自分のターンに動けない |
| **エドガン** | 蘇生2体の順番 | 4コスト以下を先に、ルック奇数なら続けて1コスト以下 |
| **メガザル** | 破壊する味方の選択 | AIは**最も脅威度の低い自分のユニット**を破壊する |
