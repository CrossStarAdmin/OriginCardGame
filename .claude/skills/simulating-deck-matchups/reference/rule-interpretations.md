# ルール解釈の記録

カードテキストと `ルール/` だけでは一意に決まらなかった箇所と、その決定。
**シミュレーターはここに書いた通りに実装されている。**

新しく解釈が必要になったら、ユーザーに確認したうえでこの表に追記する。
解釈を変えたら `sim/effects.js` も直し、変更日を書く。

## 目次

- 全体に効くもの
- カード個別
- 未確定のまま残っているもの

## 全体に効くもの

### 単体ダメージ呪文の対象（2026-08-24、2026-08-29更新）

**決定：「N体に／1体にNダメージを与える」系の単体火力（火の粉／焔弾／一手先を読む／リーゼのテンションスキル「業火」など）は、敵1体（キャラクターまたはリーダー）を選ぶ。**

2026-08-29のルール改訂で `ルール/06_キーワード能力.md` が
「対象が書かれていない効果は、敵味方のリーダーとキャラクターすべての中から1体を選んで対象にする」に変わり、
"1体を選ぶ" 部分はルールで確定した。シミュレーターは残る解釈（対象は敵側、AIが選ぶ）だけを補っている。

> 全体化する解釈に戻すと数字が大きく動く。変えるなら再計測が必要。

### 貫通の再定義と超貫通の廃止（2026-08-29、2026-08-30更新）

**決定：貫通は「キャラクターの残りHPを超えたぶんのダメージをリーダーに与える」。超貫通は廃止し、貫通に一本化。**

2026-08-29にいったん「与えたダメージと同量をリーダーにも与える」としたが、2026-08-30にはみ出しぶんへ戻した。
`sim/engine.js` の `attackUnit` は `攻撃力 − 攻撃前の相手の残りHP` を計算し、正のときだけリーダーへ加算する。
貫通を持つカードは識りすぎたヴァルザ（ルック奇数）1枚だけで、影響範囲はこのカードに閉じている。
**この変更でエルナの勝率が下がるため、それ以前の計測値とは比較できない。**

### 先攻の1ターン目はドローなし（2026-08-29）

**決定：先攻プレイヤーは最初のターンにカードを引かない。後攻は引く＋テンション2スタートで補正。**

`ルール/01_基本ルール.md`・`ルール/02_ターンの流れ.md` の改訂に追従。`sim/engine.js` の `startPhase` が
`g.turn === 1` のときドローを飛ばす。旧実装は両者が1ターン目に引いていた。
**この変更で先攻勝率が下がるため、過去の計測値とは比較できない。**

### テンションスキルの使用回数（2026-08-29）

**決定：1ターンの使用回数に上限なし（毎回テンション3が必要）。**

`ルール/05_テンション.md` の改訂に追従し、AIの「1ターン1回」制限を外した。
現行カードプールには+3以上テンションを盛る手段が無いため、実際の挙動は従来どおりほぼ1ターン1回。

### 聖水（2026-08-30）

**決定：後攻は聖水を2つ持って始める。使うとMPが1回復し、1ターンに1つまで、対戦中2つまで。**

`ルール/01_基本ルール.md`・`ルール/02_ターンの流れ.md` の改訂に追従。`sim/run.js` が後攻に `holy = 2` を配り、
`sim/ai.js` の `useHoly` が「あと1MPで手札が使える」ときに1つ切る。テンション2スタートは据え置き。
**この変更で先攻勝率が大きく下がるため、過去の計測値とは比較できない。**

### 種族タグ「聖徒」の割り当て（2026-08-24、2026-08-29更新）

**決定：`デッキ/コントロールアルベル.md` に明記された4枚（修道女キーラ／聖騎士ザキエル／老司祭ドラン／祈る巡礼者）に付与する。**

旧「冒険者」タグ（イザヤール〜レティスの6枚）をアルベルのリネームに合わせて「聖徒」に統一。
偽善のミゼリア（旧マルチェロ）と継承の大鐘（旧レティス）はテーマ上タグを持たないが、
コスト6以上の聖徒をサーチする効果は存在しないため、実挙動は旧実装と同じ。
「老司祭ドラン」の3コスト以下サーチは実質「修道女キーラ」固定。

### 効果で場に出したキャラクターの召喚時（2026-08-24）

**決定：効果で「出す」ものは召喚時を発動する（`ルール/03`「場に出た直後に発動する」に従う）。
ただしコピーを生むカードだけは例外にする。**

### 残火（アグロリーゼ）の判定タイミング（2026-08-29）

**決定：残火は「そのキャラクターが場に出たとき」に `spellsThisTurn > 0` を1回だけ判定する。**

`デッキ/アグロリーゼ.md` の用語節どおり。後からスペルを撃っても遡って発動しない。
AIは残火持ち（学舎の見習い／ギズモ／ドロテ）を出す前に、同ターンに火の粉か焔弾を撃つよう組む。

### 「全体」の範囲と、スペルの残火判定（2026-09-08）

**決定：「消えぬ焔」の『全体に3ダメージ』は敵味方すべてのリーダーとキャラクターに入る。自分のリーダーも被弾する。
残火の判定に、そのスペル自身は数えない（同ターンに別のスペルを先に使っている必要がある）。**

`ルール/06_キーワード能力.md` の記法「『全体』は敵味方すべてのリーダーとキャラクター」をそのまま適用した。
`sim/effects.js` の `castSpell` が敵味方の盤面と両リーダーへ与える。自傷ぶんは `p.leaderHp` を直接引き、
顔ダメージ統計には計上しない（傲慢のノクスの偶数面と同じ扱い）。
残火は `afterburnSpell(p)`（`spellsThisTurn > 1`）で判定する。`payAndPlay` が `castSpell` より先に
`spellsThisTurn` を増やすため、自分自身を除くには 1 ではなく 2 以上を見る必要がある。

### 師ベルゼの「このバトル中、残火状態になる」（2026-09-08）

**決定：ベルゼが場に出た時点から対戦終了まで、自分の残火が常に成立する。ベルゼが破壊されても継続する。**

`sim/engine.js` の `Player` に `afterburnAlways` を持たせ、`afterburn()` がこれを見る。
以降スペルを撃たなくても学舎の見習い・ドロテ・ギズモ・消えぬ焔の残火が通る。

### 「手札で働く」（ギズモ）（2026-09-08）

**決定：手札にある間だけ働く効果。残火が成立していればギズモのコストが3→2になる。**

`ルール/06_キーワード能力.md` に定義の無い新しい記法。残火の「場に出たとき1回だけ判定」とは別で、
手札にある間は毎回判定する。`sim/effects.js` の `handCostDelta()` を `engine.js` の `cardCost()` から呼ぶ。

### 「+X/+0」表記（消えぬ焔、師ベルゼ死亡時）（2026-08-29、2026-08-30更新、2026-09-08失効）

**決定：攻撃力のみ加算し、HP・最大HPは変えない（`ルール/03` の `+X/+Y` で Y=0）。**

2026-09-08のカード調整で消えぬ焔は全体ダメージへ、師ベルゼの死亡時は敵リーダーへの5ダメージへ差し替わり、
この項目を参照するカードは無くなった。`+X/+0` 表記自体は学舎の見習い・ドロテに残る。

## カード個別

カード名は2026-08-29のリネーム後のもの。（旧名）を併記する。

| カード | 曖昧だった点 | 決定 |
|---|---|---|
| **双子の星占いエマ&エリ**（旧双つの未来／旧わかめ王子） | コピーがまた召喚時を発動するか | **しない**。デッキトップが変わらないため無限ループになる |
| **聖獣キメラ**（旧リトルライバーン） | 「リーダーが回復する度」はどちらのリーダーか | **自分のリーダー**。実際にHPが増えたときだけ誘発（満タンでは誘発しない） |
| **姉マイア**（旧マーニャ） | テンションリンクの「場のキャラクター」の範囲 | **敵味方の全キャラクター**。自分のキャラクターにも1ダメージが入る |
| **傲慢のノクス**（旧キングレオ） | 偶数時の「味方全体」にリーダーを含むか | **含む**。味方リーダーも4ダメージを受ける |
| **深読み**（旧アルカナバースト） | ルックとドローの順番 | **ルックが先**。その結果でダメージ量（2 or 6）が決まり、そのあとドロー |
| **傷ついた巡礼者**（旧さまようたましい） | 「2ダメージを受ける」の対象 | **自分自身**。場に出た瞬間に 2/1 になる |
| **マージマタンゴ相当** | 「次のターン開始まで」動けなくする起点（火口の洞守り） | `ルール/07` に従い**効果の持ち主の次の開始フェイズ**まで。相手は自分のターンに動けない |
| **写し手ヨナ**（旧エドガン） | 蘇生2体の順番 | 4コスト以下を先に、ルック奇数なら続けて1コスト以下 |
| **継ぐ者の儀**（旧メガザル） | 破壊する味方の選択／再復活の可否 | AIは**最も脅威度の低い自分のキャラクター**を破壊する。破壊したキャラクターは復活対象から除外する（テキストの「破壊したキャラ以外」に合わせた。旧メガザルは除外していなかった） |
| **祈る巡礼者**（旧プリン） | 回復対象に自分を含むか | **含む**（テキスト「味方キャラクター全体」）。出たては満タンなので実質無変化 |
