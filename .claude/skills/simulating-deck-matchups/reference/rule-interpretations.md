# ルール解釈の記録

カードテキストと `ルール/` だけでは一意に決まらなかった箇所と、その決定。
**シミュレーターはここに書いた通りに実装されている。**

新しく解釈が必要になったら、ユーザーに確認したうえでこの表に追記する。
解釈を変えたら `sim/effects.js` も直し、変更日を書く。

## 目次

- 全体に効くもの
- カード個別
- 未確定のまま残っているもの

## 全体に効くもの

### 単体ダメージ呪文の対象（2026-08-24、2026-08-29更新）

**決定：「N体に／1体にNダメージを与える」系の単体火力（火の粉／焔弾／一手先を読む／リーゼのテンションスキル「業火」など）は、敵1体（キャラクターまたはリーダー）を選ぶ。**

2026-08-29のルール改訂で `ルール/06_キーワード能力.md` が
「対象が書かれていない効果は、敵味方のリーダーとキャラクターすべての中から1体を選んで対象にする」に変わり、
"1体を選ぶ" 部分はルールで確定した。シミュレーターは残る解釈（対象は敵側、AIが選ぶ）だけを補っている。

> 全体化する解釈に戻すと数字が大きく動く。変えるなら再計測が必要。

### 貫通の再定義と超貫通の廃止（2026-08-29、2026-08-30更新）

**決定：貫通は「キャラクターの残りHPを超えたぶんのダメージをリーダーに与える」。超貫通は廃止し、貫通に一本化。**

2026-08-29にいったん「与えたダメージと同量をリーダーにも与える」としたが、2026-08-30にはみ出しぶんへ戻した。
`sim/engine.js` の `attackUnit` は `攻撃力 − 攻撃前の相手の残りHP` を計算し、正のときだけリーダーへ加算する。
貫通を持つカードは識りすぎたヴァルザ（ルック奇数）1枚だけで、影響範囲はこのカードに閉じている。
**この変更でエルナの勝率が下がるため、それ以前の計測値とは比較できない。**

### 先攻の1ターン目はドローなし（2026-08-29）

**決定：先攻プレイヤーは最初のターンにカードを引かない。後攻は引く＋テンション2スタートで補正。**

`ルール/01_基本ルール.md`・`ルール/02_ターンの流れ.md` の改訂に追従。`sim/engine.js` の `startPhase` が
`g.turn === 1` のときドローを飛ばす。旧実装は両者が1ターン目に引いていた。
**この変更で先攻勝率が下がるため、過去の計測値とは比較できない。**

### テンションスキルの使用回数（2026-08-29）

**決定：1ターンの使用回数に上限なし（毎回テンション3が必要）。**

`ルール/05_テンション.md` の改訂に追従し、AIの「1ターン1回」制限を外した。
現行カードプールには+3以上テンションを盛る手段が無いため、実際の挙動は従来どおりほぼ1ターン1回。

### 聖水（2026-08-30）

**決定：後攻は聖水を2つ持って始める。使うとMPが1回復し、1ターンに1つまで、対戦中2つまで。**

`ルール/01_基本ルール.md`・`ルール/02_ターンの流れ.md` の改訂に追従。`sim/run.js` が後攻に `holy = 2` を配り、
`sim/ai.js` の `useHoly` が「あと1MPで手札が使える」ときに1つ切る。テンション2スタートは据え置き。
**この変更で先攻勝率が大きく下がるため、過去の計測値とは比較できない。**

### 種族タグ「聖徒」の割り当て（2026-08-24、2026-09-09更新）

**決定：カードファイルに明記された4枚（怪我をした修道女キーラ／聖騎士ザキエル／老司祭ドラン／怒れる聖職者アン）に付与する。**

旧「冒険者」タグ（イザヤール〜レティスの6枚）をアルベルのリネームに合わせて「聖徒」に統一。
偽善のミゼリア（旧マルチェロ）と継承の大鐘（旧レティス）はテーマ上タグを持たないが、
コスト6以上の聖徒をサーチする効果は存在しないため、実挙動は旧実装と同じ。
「老司祭ドラン」の3コスト以下サーチは実質「修道女キーラ」固定。

### 効果で場に出したキャラクターの召喚時（2026-08-24）

**決定：効果で「出す」ものは召喚時を発動する（`ルール/03`「場に出た直後に発動する」に従う）。
ただしコピーを生むカードだけは例外にする。**

### 残火（アグロリーゼ）の判定タイミング（2026-08-29）

**決定：残火は「そのキャラクターが場に出たとき」に `spellsThisTurn > 0` を1回だけ判定する。**

`デッキ/アグロリーゼ.md` の用語節どおり。後からスペルを撃っても遡って発動しない。
AIは残火持ち（学舎の見習い／ギズモ／ドロテ）を出す前に、同ターンに火の粉か焔弾を撃つよう組む。

### 「+X/+0」表記（学舎の見習い、ドロテ）（2026-08-29、2026-09-09更新）

**決定：攻撃力のみ加算し、HP・最大HPは変えない（`ルール/03` の `+X/+Y` で Y=0）。**
2026-09-09時点で該当するのは学舎の見習いとドロテの残火のみ。消えぬ焔と師ベルゼ死亡時は
下記のとおり別の効果に差し替わったため、この項目の対象から外れた。

### 消えぬ焔の「全体」（2026-09-09）

**決定：`ルール/06` の定義どおり、敵味方すべてのリーダーとキャラクターに3ダメージ。残火が乗ると4。**

`デッキ/アグロリーゼ/カード一覧/13_消えぬ焔.md` の現行テキストに合わせた。
自分の盤面と自分のリーダーも巻き込む。`デッキ/アグロリーゼ/overview.md` には旧テキスト
（味方全体に+1/+0と速攻）の記述が残っているが、**カードファイル側を正とする。**
スペル自身の残火は、そのスペルより前に別のスペルを撃っている必要がある
（`p.spellsThisTurn > 1` で判定）。

> この変更でリーゼの勝率が大きく下がるため、2026-08-30以前の計測値とは比較できない。

### 師ベルゼの「このバトル中、残火状態になる」（2026-09-09）

**決定：師ベルゼを場に出した瞬間から試合終了まで、残火が常に成立する。ベルゼが破壊されても継続する。**

`sim/engine.js` の Player に `afterburnAlways` を持たせ、`afterburn(p)` が
`afterburnAlways || spellsThisTurn > 0` を返す。スペルを撃たなくても学舎の見習い・ドロテ・
消えぬ焔・ギズモの残火が乗るようになる。

### ギズモの「手札で働く」（2026-09-09）

**決定：手札にある間、残火が成立していればコストが3→2になる。**

`sim/engine.js` の `cardCost` から `effects.handCostMod` を呼んで補正する。
場に出たあとは常在の速攻のみで、残火は参照しない。

### 聖獣キメラの効果タイミング（2026-09-09、同日ナーフで更新）

**決定：召喚時に自分のリーダーを2回復。死亡時に敵キャラクター1体へ2ダメージ。**

旧実装の「リーダーが回復するたび2ダメージ」の継続誘発は廃止済み。
そのあと計測を受けて、召喚時の2ダメージが死亡時へ移り、回復が5→2に下がった。
テキストの「リーダーのHPを2回復」はどちら側か書かれていないが、**自分のリーダー**として実装している。
`デッキ/コントロールアルベル/overview.md` には旧テキストの記述が残っているが、
**カードファイル側を正とする。**

### 「特技」＝スペル（2026-09-09）

**決定：偽善のミゼリアの「次に使う特技のコストを0にする」の「特技」はスペルを指す。**

`ルール/08_用語集.md` に「特技」の項目は無く、表記ゆれの統一表にも載っていない。
現行カードプールにスペル以外の使用カード（武器）が存在しないため、スペルとして実装した。
**用語集側に「特技→スペル」を足すか、カードテキストをスペルに直すのが望ましい。**

### 偽善のミゼリアのコスト0（2026-09-09）

**決定：そのターン中、次に使うスペル1枚だけがコスト0。持ち越しはしない。**

`sim/engine.js` の既存の `spellDiscount` を使い、スペルを1枚使った時点で戻す。
開始フェイズでも0に戻るので、ターンをまたいでは残らない。
デッキに「死のパレード」が残っていない場合はサーチだけ不発になり、コスト0は適用される。

## カード個別

カード名は2026-09-09のリネーム後のもの。（旧名）を併記する。

| カード | 曖昧だった点 | 決定 |
|---|---|---|
| **双子の星占いエマ&エリ**（旧双つの未来） | コピーがまた召喚時を発動するか | **しない**。デッキトップが変わらないため無限ループになる |
| **姉マイア** | テンションリンクの「場のキャラクター」の範囲 | **敵味方の全キャラクター**。自分のキャラクターにも1ダメージが入る |
| **傲慢のノクス** | 偶数時の「味方全体」にリーダーを含むか | **含む**。味方リーダーも4ダメージを受ける |
| **深読み** | ルックとドローの順番 | **ルックが先**。その結果でダメージ量（2 or 6）が決まり、そのあとドロー |
| **傷ついた巡礼者** | 「2ダメージを受ける」の対象 | **自分自身**。場に出た瞬間に 2/1 になる |
| **火口の洞守り** | 「次のターン開始まで」動けなくする起点 | `ルール/07` に従い**効果の持ち主の次の開始フェイズ**まで。相手は自分のターンに動けない |
| **写し手ヨナ** | 蘇生2体の順番 | 4コスト以下を先に、ルック奇数なら続けて1コスト以下 |
| **死のパレード**（旧継ぐ者の儀） | 「2体まで」の解釈 | AIは**常に2体復活させる**。味方を破壊する旧テキストは消えたので生け贄は取らない |
| **怒れる聖職者アン**（旧祈る巡礼者） | 回復対象に自分を含むか | **含む**（テキスト「味方キャラクター全体」）。リーダーは含まない |
| **癒しの人形**（旧癒しの人形ホミ） | 「1体のHPを1回復」の対象 | **自分側**。減っているキャラクターを優先し、いなければ自分のリーダー |
| **禁術・蘇生**（旧間に合わせの蘇生） | 復活後のHP | **満タン**。旧テキストにあった「HP1で」の指定が消えたため |
| **聖鳥リフルエル**（旧継承の大鐘） | 出した2体の召喚時 | **発動する**。老司祭ドランが出るとさらに聖徒を呼ぶ連鎖も起きる |
