# 登場人物のストーリーを作る

カードゲームの登場人物のストーリーを考えます。このストーリーによって、カード効果を考える背景になったり、どういうキャラクターイラストを作成すればいいのかを考える手助けになります。

このスキルでは各キャラクターの背景ストーリーの基盤を作成します。

## 各種ステップ
以下チェックシートに従って、ステップごとにストーリーの作成を行います。

- [ ] Step1. 全体ストーリーの理解
- [ ] Step2. 作成キャラの簡易的なストーリーの理解
- [ ] Step3. 作成キャラのストーリードラフト作成
- [ ] Step4. 作成キャラのストーリー作成
- [ ] Step5. 最終チェック

---

## Step1. 全体ストーリーの理解

以下の内容を読んで全体のストーリーを理解する
- **ストーリー理解**：`バックエンドストーリー/全体ストーリー清書.md` — 世界設定・用語集・二つの道
- **キャラクター理解**`バックエンドストーリー/キャラクター紹介.md` — 全員の立場と六罪の割り当て

---

## Step2. 作成キャラの簡易的なストーリーの理解

全体ストーリーと各キャラクター紹介を基に以下の６項目を決定する。

| 項目 | 内容 |
|---|---|
| **町** | どの結晶の町か。暮らしぶりと、結晶がどこに置かれているかまで決める |
| **六罪** | どの罪が送られたか |
| **心の支え** | 誰が狂わされたか。**主人公にとって近い人物であること** |
| **歪め方** | その人の美点が、どう罪に化けたか |
| **立場** | 封印 / 討伐 / 未定。**個人的な理由が要る** |
| **負け方** | 魔王にどう挑んで、どう届かなかったか。全員違うこと |

---

## Step3. 作成キャラのストーリードラフト作成

次の順番で骨組みを組む。各項目を１～３行ほどで理解しやすいように書く。
ファイルへの出力はしなくていい。

1. **町を決める** — 暮らしと結晶の置き場所。ここが後で必ず効く
2. **心の支えの「美点」を決める** — 歪める前の姿。優しさ、探究心、憧れ、律儀さなど
3. **その美点を罪の方向へ少しだけ倒す** — これが洗脳の中身になる
4. **主人公が何をしに行ったかを決める** — 倒しに / 止めに / 鎮めに。ここで話の質が決まる
5. **払った代償を書く** — 何を失ったか、何日かかったか
6. **魔王への負け方を書く**
7. **立場と決め台詞**

ユーザーと壁打ちしながら方向性を決定する。
ユーザーが納得するまで次の項目に進まない

---

## Step4. 作成キャラのストーリー作成

テンプレートに沿って、内容を肉付けしていく。

### ファイルとテンプレート
それぞれ以下の場所
- **置き場所**：`バックエンドストーリー/各キャラクターのストーリー/N_【職業名】【キャラクター名】.md`
- **テンプレート**: `.claude/skills/creating-character-story/template/template.md`

### 文体
- 一文を短く。体言止めを混ぜる
- **説明しない。出来事で見せる**
- 感情語を書かない。「悲しかった」ではなく、何が起きたかを置く
- 強調（`**`）は要点だけ。多用すると効かなくなる
- 決め台詞は引用（`>`）で置く

---

## Step5. 最終チェック

書き終わったら、全項目を通す。

### 品質チェック

- [ ] **話全体に違和感がない** — 不自然な動機や、その人らしくない行動をとっていない
- [ ] **主人公の動機に一貫性がある** — 町を出た理由から決め台詞まで、一本の線で繋がっている
- [ ] **主人公の特徴がわかる** — 何を大事にし、どう戦う人間かが読んで掴める
- [ ] **なれのはてが主人公と近い** — 他人ではなく、心の支えだった人物
- [ ] **なれのはてが悪人になっていない** — 最後まで善いことをしているつもりでいる
- [ ] **なれのはてとの決着が描けている** — 何をしに行き、どうなり、何を失ったか
- [ ] **六罪への感情が表れている** — 六罪をどう思っているかが、行動か台詞に出ている
- [ ] **魔王に挑んだ形跡がある** — 挑み方と、届かなかった理由が書かれている
- [ ] **決め台詞が1つある** — 立場を一行で言い切る。地の文で説明せず本人に言わせる

### 他ファイルとの整合

- [ ] `キャラクター紹介.md` の該当セクションを短縮版として揃えた
- [ ] 世界の仕組みに触ったなら、`全体ストーリー清書.md` の用語集・バックストーリーと矛盾がない
- [ ] 六罪のやり口を変えたなら、`キャラクター紹介.md` の六罪の表も直した

すべてにチェックがついたら完了。1つでも漏れたらStep4に戻る。

---

## 注意事項

このスキルでやってほしくないこと。

- **記憶や推測で設定を書かない。** Step1の2ファイルを読まずに書き始めない
- **既存の世界設定を勝手に変えない。** 用語・六罪の割り当て・二つの道の構造を変える必要が出たら、書き換える前に確認を取る
- **他キャラのストーリーファイルを、そのキャラの作業ついでに書き換えない**
- **なれのはてを悪人として書かない。** 憎悪・私欲を動機にしない
- **代償のない強さを書かない。** 戦い方や性格を、過去の代償と切り離して説明しない
- **他キャラと同じ負け方をさせない。** 魔王への挑み方は全員違うこと
- **感情語で説明しない。** 「悲しかった」「絶望した」で片付けない
- **手数を増やさない。** 六罪の所業も戦闘描写も、盛るほど弱くなる
- **全項目を埋めることを目的にしない。** テンプレートの見出しは話に合わせて変えてよい
- **未回収の穴をその場で回収しない。** 説明し切らずに残す
- **Step5を飛ばさない。** 品質チェックと他ファイルの整合を通さずに完了としない
