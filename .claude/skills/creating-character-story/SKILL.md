# 登場人物のストーリーを作る

カードゲームの登場人物のストーリーを作ります。このストーリーが、カード効果を考える背景になり、どういうキャラクターイラストを作ればいいかの手がかりになります。

## このスキルで使う語

`全体ストーリー清書.md` の用語集に合わせる。以下の語だけを使い、言い換えない。

| 語 | 指すもの |
|---|---|
| **主人公** | いま書いているキャラクター |
| **町の支柱** | 六罪に洗脳される前の人物。主人公にとって近い人物 |
| **なれのはて** | 町の支柱が罪に呑まれきり、人でなくなった姿 |
| **濁る** | 罪を植えつけられ、その罪に呑まれていくこと |
| **世界への立場** | 封印 / 討伐 / 未定 |

## 各種ステップ

以下のチェックリストを応答にコピーし、完了したステップにチェックを入れながら進める。

```
ストーリー作成の進捗:
- [ ] Step1. 全体ストーリーの理解
- [ ] Step2. 作成キャラの簡易的なストーリーの理解
- [ ] Step3. 作成キャラのストーリードラフト作成
- [ ] Step4. 作成キャラのストーリー作成
- [ ] Step5. 最終チェック
```

---

## Step1. 全体ストーリーの理解

必ず読む。記憶や推測で書かない。

- **世界設定**：`バックエンドストーリー/全体ストーリー清書.md` — 用語集・二つの道
- **キャラクター**：`バックエンドストーリー/キャラクター紹介.md` — 全員の立場と六罪の割り当て

---

## Step2. 作成キャラの簡易的なストーリーの理解

全体ストーリーとキャラクター紹介を基に、以下の6項目を決定する。

| 項目 | 内容 |
|---|---|
| **出身町** | どの結晶の町か。暮らしぶりと、結晶がどこに置かれているかまで決める |
| **六罪** | どの罪が送られたか |
| **町の支柱** | 誰が濁らされたか。**主人公にとって近い人物であること** |
| **濁り方** | その人の美点が、どう罪に化けたか |
| **世界への立場** | 封印 / 討伐 / 未定。**個人的な理由が要る** |
| **魔王への挑み方** | どう挑んで、どう届かなかったか。全員違うこと |

**六罪は6体で、1つの町に1体**。`キャラクター紹介.md` の六罪の表を見て、他キャラに割り当て済みの罪と重複させない。

---

## Step3. 作成キャラのストーリードラフト作成

次の順番で骨組みを組む。各項目を1〜3行ほどで理解しやすいように書く。
ファイルへの出力はしなくていい。

1. **出身町を決める** — 暮らしと結晶の置き場所。ここが後で必ず効く
2. **町の支柱の「美点」を決める** — 濁る前の姿。優しさ、探究心、憧れ、律儀さなど
3. **その美点を罪の方向へ少しだけ倒す** — これが洗脳の中身になる
4. **主人公が何をしに行ったかを決める** — 倒しに / 止めに / 鎮めに。ここで話の質が決まる
5. **払った代償を書く** — 何を失ったか、何日かかったか
6. **魔王への挑み方を書く**
7. **世界への立場と決め台詞**

ユーザーと壁打ちしながら方向性を決定する。
ユーザーが納得するまで次の項目に進まない。

### 動機に飛躍がないか

ドラフトの段階で必ず確かめる。最も多い失敗。

- **悪い例**：「なぜ自分の町だけがと吹き込まれた → 自分の町を焼いた」
  怒りの矛先が外に向くはずなので繋がっていない
- **良い例**：「理由のない怒りを深層に埋められた → 的がないので、いちばん近くにある町に向いた」

**罪の性質と、その人の行動が、一本の線で結べること。**

### 性格ではなく代償から書く

- **悪い例**：「速いのは短気だから」
- **良い例**：「速いのは、迷って町を半分失ったから」

**戦い方は必ず、過去に払った代償の形にする。**

## Step4. 作成キャラのストーリー作成

テンプレートに沿って、内容を肉付けしていく。

### ファイルとテンプレート

- **置き場所**：`バックエンドストーリー/各キャラクターのストーリー/N_職業名名前.md`
  例：`1_焔術士リーゼ.md`
- **N**：`キャラクター紹介.md`「勇者たち」の通し番号に合わせる（① → `1`）。
  そこに載っていないキャラなら、既存ファイルの最大番号 + 1
- **テンプレート**：`template/template.md` をコピーして使う

### 書き方のルール

- 六罪がしたことは**手数を少なく**。説教を一度、本を一冊置いた、一言囁いた、金を積んだ。それで足りる
- なれのはては**最後まで善いことをしているつもり**でいる。憎悪や私欲で動かさない
- 主人公が何をしに行ったかを先に書く。**「鎮めに行って、鎮められなかった」のほうが「倒しに行って倒した」より必ず強い**
- 世界への立場には**個人的な理由**を書く。正論だけでは弱い。上に書いた代償から立場が出ていること
- **特定の誰かと噛み合わない理由**を1つ足す
  （例：話して分からせようとして失敗した側なので、頭を下げて回る相手に一番冷たい）
- 後で使える**未回収を1つ残す**（燃やしていない本、語らない理由、傷んだ結晶）
- 見出し名は話に合わせて変えてよい。型より、その話に合う切り口を優先する

### 文体

- 一文を短く。体言止めを混ぜる
- **説明しない。出来事で見せる**
- 感情語を書かない。「悲しかった」ではなく、何が起きたかを置く
- 強調（`**`）は要点だけ。多用すると効かなくなる
- 決め台詞は引用（`>`）で置く

---

## Step5. 最終チェック

書き終わったら、全項目を通す。

### 品質チェック

- [ ] **話全体に違和感がない** — 不自然な動機や、その人らしくない行動をとっていない
- [ ] **主人公の動機に一貫性がある** — 町を出た理由から決め台詞まで、一本の線で繋がっている
- [ ] **主人公の特徴がわかる** — 何を大事にし、どう戦う人間かが読んで掴める
- [ ] **なれのはてが主人公と近い** — 他人ではなく、町の支柱だった人物
- [ ] **なれのはてが悪人になっていない** — 最後まで善いことをしているつもりでいる
- [ ] **なれのはてとの決着が描けている** — 何をしに行き、どうなり、何を失ったか
- [ ] **六罪への感情が表れている** — 六罪をどう思っているかが、行動か台詞に出ている
- [ ] **六罪が他キャラと重複していない** — `キャラクター紹介.md` の六罪の表と突き合わせた
- [ ] **魔王に挑んだ形跡がある** — 挑み方と、届かなかった理由が書かれている
- [ ] **決め台詞が1つある** — 立場を一行で言い切る。地の文で説明せず本人に言わせる

### 仕上げ

- [ ] テンプレートの `<!-- -->` コメント行を全て削除した

### 他ファイルとの整合

- [ ] `キャラクター紹介.md` の該当セクションを短縮版として揃えた
- [ ] 世界の仕組みに触ったなら、`全体ストーリー清書.md` の用語集・バックストーリーと矛盾がない
- [ ] 六罪のやり口を変えたなら、`キャラクター紹介.md` の六罪の表も直した

すべてにチェックがついたら完了。1つでも漏れたらStep4に戻る。

---

## 注意事項

このスキルでやってほしくないこと。

- **記憶や推測で設定を書かない。** Step1の資料を読まずに書き始めない
- **既存の世界設定を勝手に変えない。** 用語・六罪の割り当て・二つの道の構造を変える必要が出たら、書き換える前に確認を取る
- **用語を言い換えない。** 「このスキルで使う語」の表にある語だけを使う
- **他キャラのストーリーファイルを、そのキャラの作業ついでに書き換えない**
- **なれのはてを悪人として書かない。** 憎悪・私欲を動機にしない
- **代償のない強さを書かない。** 戦い方や性格を、過去の代償と切り離して説明しない
- **他キャラと同じ挑み方・同じ罪を割り当てない**
- **感情語で説明しない。** 「悲しかった」「絶望した」で片付けない
- **手数を増やさない。** 六罪の所業も戦闘描写も、盛るほど弱くなる
- **全項目を埋めることを目的にしない。** テンプレートの見出しは話に合わせて変えてよい
- **未回収の穴をその場で回収しない。** 説明し切らずに残す
- **Step3でユーザーの合意を取らずにStep4へ進まない**
- **Step5を飛ばさない。** 品質チェックと他ファイルの整合を通さずに完了としない
