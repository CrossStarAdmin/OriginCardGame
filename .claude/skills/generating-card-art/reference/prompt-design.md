# プロンプト設計

`art/style.json` と `art/subjects.js` の書き方と、絵が破綻したときの直し方。

## 英文と和訳の対

**APIへ送られるのは英文だけ。和訳は人が読んで確認するためのもの。**
ユーザーは日本語で意図を述べ、英語のプロンプトは読まない。だから対訳が崩れると、
**間違ったプロンプトのまま課金し続けることになる。**

| ファイル | 英文のキー | 和訳のキー |
|---|---|---|
| `style.json` | `en` | `和訳` |
| `subjects.js` | `en` | `jp` |

**片方だけ直さない。** 直したら必ず突き合わせる。

```bash
node .claude/skills/generating-card-art/art/review.js --card ドロテ
```

## プロンプトの組み立て

`art/prompt.js` が5区画を順に連結する。**後ろの区画ほど全カード共通で、前ほど個別。**

| 区画 | 出どころ | 効く範囲 |
|---|---|---|
| `Subject`（被写体） | `subjects.js` の `CHARACTERS` + カードの本文 | そのカードだけ |
| `Composition`（構図） | `style.json` の `composition[種類]` + `frameSafe` | 種類（リーダー／キャラクター／スペル）ごと |
| `Setting and palette`（色と舞台） | `style.json` の `classTone[クラス]` + プリセットの `lighting` | クラスごと＋絵柄ごと |
| `Style`（画風） | `style.json` の プリセットの `base` | 絵柄ごと |
| `Strict exclusions`（除外） | `style.json` の `exclusions` | 全カード |

**直す前に、どの範囲の問題なのかを決める。** 1枚だけおかしいなら `subjects.js`、
同じクラスが全部おかしいなら `classTone`、全部おかしいなら プリセットの `base` を触る。

## style.json の書き方

### プリセット

`presets` に絵柄を並べ、`preset` で既定を決める。`--style 名前` で切り替えられる。

| プリセット | 中身 |
|---|---|
| `anime` | アニメ塗り。カード枠とサンプルカードに合う明るい絵柄。**既定** |
| `oil` | 重厚なファンタジー油彩。暗く劇的 |
| `watercolor` | ダークファンタジー水彩。にじみと余白 |

新しい絵柄は `presets` に `base` と `lighting` の対を1ブロック足すだけで増やせる。
**`base` は塗りと質感、`lighting` は明るさと光の当て方**に分けてある。
「暗すぎる」だけなら `lighting` を、「塗りを変えたい」なら `base` を触る。

### その他の項目

- `composition` — 種類別の構図。`スペル` だけは人物ではなく現象を主役にしている
- `frameSafe` — カード枠のアート窓に嵌めるための制約。**下記の理由があるので消さない**
- `classTone` — クラス別の色と舞台。デッキが増えたらここにクラスを足す
- `exclusions` — 文字・枠・分割構図の禁止
- `aspect` — 生成する縦横比。`frame.json` のアート窓の比に合わせてある

### frameSafe が今の形になっている理由

`カードフレーム/frame.json` の実測で、**枠はイラストの上に文字を重ねない**ことが分かっている。
カード名・効果・コスト・攻撃力・HPはすべて枠側の専用欄にある。

したがって課すのは次の3点に絞ってある。

- 窓いっぱいに描かせる（絵の中に余白や縁を作らせない）
- 外周5%に重要なものを置かせない（嵌め込みで切れる）
- 最下部だけ静かにする（下端が切れる）

**「枠のスペースを空けさせる」指示を足さない。** 絵が小さくなるだけで、枠は何も重ねない。

## subjects.js の書き方

### 人物は CHARACTERS に集約する

複数カードに出る人物（ヴァルザ、ベルゼ、六罪、リーダー）は `CHARACTERS` に外見を1か所だけ書き、
カード側は `character: '名前'` で参照して、そのカードでの状況だけを書く。

```js
'相棒ヴァルザ':       { character: '相棒ヴァルザ', jp: '机に身を乗り出して振り返る', en: '…' },
'識りすぎたヴァルザ': { character: '識りすぎたヴァルザ', jp: '結晶室に浮かんでいる', en: '…' },
```

「相棒」と「識りすぎた」は同一人物だが別人格・別形態なので、意図的に別エントリにしている。
**同じ姿で出したい人物を分けて書かない。顔が変わる。**

### 外見は固定要素、状況は可変要素

`CHARACTERS` に書くのは髪・目・服・年齢・体格・雰囲気。**ポーズや背景は書かない。**
カード側に書くのはポーズ・動作・背景・そのカードの一瞬。**髪型や服は書かない。**
この境界を守らないと、カードごとに服が変わる。

### 効果テキストをそのまま渡さない

「敵全体に4ダメージ」を英訳しても絵にならない。
**その効果が起きている瞬間の見た目**に翻訳して書く。

## よくある破綻と対処

| 症状 | 直す場所 |
|---|---|
| 画像に文字・数字が入る | `exclusions` を強める。それでも残るなら被写体から本・巻物・看板など文字が載る物を減らす |
| 同一人物の顔が毎回違う | `CHARACTERS` を参照せずカード側に外見を書いていないか確認する。特徴を2〜3個に絞ると安定する |
| 被写体が中央に小さく浮く | `composition` の「fills most of the frame」を強める |
| 絵の中に額縁や黒帯が描かれる | `frameSafe` の「no border, margin, vignette or matte」を強める |
| 暗すぎる／明るすぎる | プリセットの `lighting` |
| キャラが複数人写る | `exclusions` の `single subject only` を強め、被写体から他の人物を消す |
| クラスの色が出ない | `classTone` の色名を減らして絞る。色を並べすぎると効かない |

**プロンプトを長くするほど個々の指示は効かなくなる。** 効かない指示を足すのではなく、競合している指示を消す。

## 安全フィルタで弾かれたとき

Googleは `finishReason: IMAGE_SAFETY` を返し、画像が来ない。**ブロック分は課金されない。**

実例：`学舎の見習い` の「怯えて目を見開いた若い見習い」が弾かれた。
**幼い人物＋炎＋恐怖の組み合わせ**が引っかかったとみられる。
「若い成人の見習いが眉を寄せて集中している」に書き換えて通った。

年齢を明示して成人にする、恐怖・苦痛の描写を外す、が効きやすい。

## APIの設定

`art/providers/` に実装がある。既定は Google。

| プロバイダ | 既定モデル | 縦横比の指定 |
|---|---|---|
| `google` | `gemini-2.5-flash-image` | `imageConfig.aspectRatio`。4:5 が使える |
| `google`（`imagen-` 始まり） | — | `:predict` に切り替わる。4:5 が無いので 3:4 を使う |
| `openai` | `gpt-image-1` | 縦横比ではなくピクセル指定。`SIZE_BY_ASPECT` で読み替えている |

429・5xx は指数バックオフで最大4回リトライする。それ以外のHTTPエラーは即座に失敗させる。
**残高切れ（`credits are depleted`）は429で返るが、待っても回復しないのでリトライせず落とす。**
