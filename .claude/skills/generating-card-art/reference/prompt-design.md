# プロンプト設計

絵の指定の書き方と、絵が破綻したときの直し方。

## どこに何を書くか

**APIへ送られるのは日本語だけ。**英訳は送信直前にシステムが行うので、mdに英語を書かない。

`art/prompt.js` が下の順に連結する。**前ほど強く効く。**

| 区画 | 出どころ | 効く範囲 |
|---|---|---|
| 絵柄 | `イラスト/共通ルール.md` の `## 絵柄` | 全カード |
| 画面の使い方 | `イラスト/共通ルール.md` | 全カード |
| 描かせないもの | `イラスト/共通ルール.md` | 全カード |
| 外見 | カードmdの `### 外見` | そのカードだけ |
| 情景 | カードmdの `### 情景` | そのカードだけ |
| 背景 | カードmdの `### 背景` | そのカードだけ |
| デッキ共通の見た目 | `overview.md` の「見た目の共通ルール」 | デッキごと |
| 構図 | `イラスト/共通ルール.md` の `## 構図` | 種類ごと |

**画面の使い方と描かせないものを前に置いているのは、末尾だと効かないから。**
末尾に置いていた頃、文字や白い帯が絵に描き込まれる事故が繰り返し起きた。**この順序を戻さない。**

**直す前に、どの範囲の問題なのかを決める。**
1枚だけおかしいならカードmd、同じデッキが全部おかしいなら overview.md、
全デッキおかしいなら 共通ルール.md。

## カードmdの3区画

### 外見

`年齢・性別 → 髪 → 瞳 → 服装 → 雰囲気の一文` の順に書く。

- **同じ町の人間は髪と瞳を揃える。** 並べたとき同じ土地の人間に見える
- **複数のカードに出る人物は、同じ特徴を書く。** 書き分けると別人の絵になる
- **人でないものは「人ではない」と明記する。** 獣・機構・魔族・現象は、書かないと人型で出る

### 情景

このカードで何をしているか。1〜3文。

- **接地を書く。** 「ドームの頂に立つ」だけだと、ドームが手前に置かれただけの絵になる。
  「曲面が足元に広がり、片足を頂点にかけて体重を預けている」まで書くと乗って見える
- **視線を書く。** 顔の向きは「見上げている」より「顔を斜め上に向け」のほうが効く
- **物語の経緯を書かない。** 絵にならない

### 背景

明暗と空気だけ。**物語の説明は書かない。**
`overview.md` の「見た目の共通ルール」のどこに当たるかを1行で指定する。

## デッキの見た目の共通ルール

`overview.md` の末尾に3〜4項目。決めるのは4つ。

| 項目 | 決めること |
|---|---|
| 光源と配色 | 何が画面を照らすか。基調色と差し色 |
| 力の見た目 | このクラスの魔法がどう見えるか。他の記号を使わないことも書く |
| 明暗の振り分け | どのカードが明るく、どれが暗いか |
| 人物の描き分け | この町の人間に共通する特徴 |

**明暗の振り分けは必ず入れる。**これが無いと40枚が同じ色の泥になる。
振り分けの軸は物語（前半／後半）でもコスト帯でもよいが、**どのカードがどちらかを決められる軸**にする。

## 実際に起きた失敗と直し方

### 文字が描き込まれる

**症状**：画面に崩れた英字や、勝手に作られた技名が描かれる。

**原因**：外見や情景の記述が、そのまま文字として画面に出る。特に**否定文**が出やすい。

- 「星を読む道具は何ひとつ持たない」→ `no star-reading tools` が画面に描かれた
- 技が主役のスペルカードで、モデルが技名を書きたがった

**直し方**：否定を肯定に書き換える。「手には何も持たず、身ひとつで踊る」。
スペルには「技の名前や説明を画面に書き込まない」を情景に足す。

### 白い縁や台紙が付く

**症状**：絵が白い枠の中に収まってしまい、カード枠の中で二重に額装される。

**原因**：「小さな霊」のように**小さいと書くと、モデルが小さく描いて周囲に余白を作る**。
引きの構図を指定したときにも出る。

**直し方**：大きさは基準を示す（「人の3倍ほど」）。
情景に「画面いっぱいに大きく捉え、周囲に余白を作らない」を足す。

### 効果テキストの帯が絵に描かれる

**症状**：画面下部に、文字を入れるための半透明の帯が描かれる。

**原因**：`共通ルール.md` に「画面の下4分の1は効果テキストの帯に隠れる」と書いていた。
**英訳されると「帯で覆われる」となり、モデルがその帯を描いた。**

**直し方**：帯を主語にしない。「下4分の1には顔や主役を置かず、静かな背景のままにする」と書き、
描かせないものに「文字を入れるための帯・バナー・半透明の板を描かない」を足す。**この書き方を崩さない。**

### 乗っている感が出ない

**症状**：「〜の上に立つ」と書いたのに、その上に乗って見えない。

**原因**：バストアップなどで**足元が画面に入っていない**。接地部分が見えないと乗って見えない。

**直し方**：接地の描写を書き、構図を「膝から上」まで引いて足元を画面に入れる。

### 顔が小さくなる

**症状**：全身にすると顔と装飾が小さく、誰だか分からない。

**原因**：リーダー枠のアート窓はほぼ正方形（0.93）なので、縦長の絵は上下が切られる。

**直し方**：そのカードの情景に「腰から上のバストアップ。**全身は描かず**」と書く。
共通ルールの構図が後から「全身」と言うので、**打ち消す一文が要る。**
