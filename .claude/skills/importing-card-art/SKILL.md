# 外部で作ったイラストを取り込む

**やることは1つだけ。`取り込み/` に置かれた画像を、カードにできる形に揃える。**

画像生成はしない。プロンプトを出したいなら `showing-card-prompt`、
APIで生成したいなら `generating-card-art`。

## 何をするか

`取り込み/<カード名>.png` を見つけて、こうする。

| | |
|---|---|
| 画像 | `イラスト/<デッキ名>/<カード名>.png` へ**移す** |
| `.json` | 同じ場所に作る。カード情報と、そのカードのプロンプトが入る |
| 取り込み/ | 空になる |

**`.json` が要る理由**は `compose.ps1` がそれを読んでカードを組むため。
`provider: "manual"` と `tool` が入るので、**後から見て手で作った1枚だと分かる。**

## コマンド

```bash
node .claude/skills/importing-card-art/import.js
```

日本語パスで落ちる場合は、フルパスのnodeを使う。

```bash
"C:/Users/beron/scoop/apps/nvm/current/nodejs/nodejs/node.exe" .claude/skills/importing-card-art/import.js
```

| オプション | 意味 |
|---|---|
| `--dry-run` | 移さずに、何が取り込まれるかだけ出す |
| `--tool <名前>` | `.json` に記録する作成元。既定は `ChatGPT` |

デッキは指定しない。**カード名から自動で探す。**

## 進め方

1. **`--dry-run` で先に確認する。** 差し替えになる絵があるかを見る
2. 問題なければ本実行する
3. 出力の最後に**合成コマンドが出る**ので、それを実行する
4. できたカードを Read で開いて確認する（確認項目は `showing-card-prompt` の SKILL.md にある）

## 出る警告

| 表示 | 意味 |
|---|---|
| `差替` | 同名の画像が既にあり、上書きした |
| `※ 縦横比が 4:5 から離れている` | 合成時に上下か左右が切られる。顔が欠けないか確認する |
| `※ カードmdの 外見／情景 が空` | 絵の指定が書かれていないカード。名前を間違えている可能性がある |
| `NG カードが見つからない` | ファイル名がカード名と一致していない |

## 注意事項

- **PNGだけ扱う。** それ以外は取り込まずに残す
- **`差替` が出たら、ユーザーに確認してから進める。** 採用済みの絵を消すことになる
- **ファイル名を推測で直さない。** 一致しないなら、どのカードのつもりか本人に聞く
- **画像を生成しない。** 生成は `generating-card-art` の役目
- **取り込んだあと、必ず合成まで通して結果を見る。** 縦横比が違うと顔が切れることがある
