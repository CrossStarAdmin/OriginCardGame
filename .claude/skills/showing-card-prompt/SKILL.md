# カードのプロンプトを出す

**やることは1つだけ。カード名からプロンプトの文面を出す。**

画像生成はしない。ファイルも書き換えない。APIを呼ばないので課金は発生しない。

## コマンド

```bash
node .claude/skills/showing-card-prompt/show.js <カード名>
```

日本語パスで落ちる場合は、`generating-card-art` の SKILL.md と同じくフルパスのnodeを使う。

```bash
"C:/Users/beron/scoop/apps/nvm/current/nodejs/nodejs/node.exe" .claude/skills/showing-card-prompt/show.js マルカ
```

| 使い方 | 結果 |
|---|---|
| `show.js マルカ` | マルカのプロンプトを出す |
| `show.js マルカ ドロテ` | 複数まとめて出す |
| `show.js マルカ --style 油彩` | 絵柄を変えて出す（既定は `イラスト/共通ルール.md` の（既定）） |
| `show.js マルカ --no-clip` | クリップボードに入れず、本文を画面に出す |

カード名は部分一致でも引ける。複数に当たったら候補を出して止まる。

## どこから作られるか

**プロンプトの組み立ては `システム/` の共有コアを使っている。**
`generating-card-art` も同じコアを使うので、**同じカードなら、このスキルが出す文とAPI生成が送る文は完全に同じ**になる。
スキル同士は直接依存していない。

| 範囲 | 場所 |
|---|---|
| 全カード共通 | `イラスト/共通ルール.md` |
| デッキごと | `デッキ/<デッキ名>/overview.md` の「見た目の共通ルール」 |
| カード1枚ごと | `デッキ/<デッキ名>/カード一覧/*.md` の `## 絵` |

**文面を変えたいときは、このスキルではなく上の3つのmdを直す。**

## 進め方

1. `show.js <カード名>` を実行する
2. **出力をそのままユーザーに見せる。** 要約したり書き換えたりしない
3. 英語版が欲しいと言われたら、その場で訳して返す（APIは使わない）
4. ユーザーが外部ツールで絵を作って**ファイルのパスを教えてきたら、下の手順で確認する**

## できた絵を確認する

画像ファイルを Read で開いて、**プロンプトの指定と突き合わせる。**
プロンプトは「こう描け」の集合なので、そのまま検査項目になる。

```
絵の確認:
- [ ] 文字・数字・署名が描き込まれていないか
- [ ] 白い縁・余白・帯・半透明の板が付いていないか
- [ ] 髪の色・瞳の色・年齢・服装が カードmdの「外見」どおりか
- [ ] 同じ人物が出る他のカードと、顔と服装が揃っているか
- [ ] 立っているもの・乗っているものが接地して見えるか
- [ ] 明暗が overview の「見た目の共通ルール」に沿っているか
- [ ] 縦横比。4:5 に切ったとき、頭や足が切れないか
```

**確認の限界を、必要ならユーザーに伝える。**

- 縮小された画像を見ているので、**指の本数・細かい模様・小さな文字は当てにならない**
- 色は「藍色っぽい」までしか言えない。数値では測っていない
- **2枚を同時に並べて見られない。**1枚ずつ読んで記憶で比べるので、同一人物の照合は明らかな差しか拾えない

**「明確な事故は拾えるが、絵としての良し悪しの微妙な差は当てにならない」**が実態。
最終判断はユーザーがする。**良し悪しを断定しない。**

ずれていたら、直すのはカードmdの `## 絵`。直したら `show.js` でプロンプトを出し直す。

## 出力の形

**カード1枚のときは、プロンプトをクリップボードへ直接入れる。**画面には出さない。
長いプロンプトをターミナルから選択してコピーするのが面倒なため。

```
★ プロンプトをクリップボードにコピーした。ChatGPTへそのまま貼り付ける
```

この行が出たら、**本文を会話に貼り直さない。**ユーザーはもう貼り付けられる状態にある。
「コピーしました」と伝えて、`▼ 生成するときの設定` の内容だけ渡す。

クリップボードに入らないのは次の場合。そのときは本文が画面に出るので、そのまま見せる。

- **複数枚まとめて出したとき**（クリップボードは1つしか持てない）
- `--no-clip` を付けたとき
- `clip` が使えない環境のとき

**縦横比の情報はプロンプト本文の中に入れない。**
本文の「描かせないもの」で数字を禁じているので、`1024x1536` が絵に描き込まれる事故を避けるため。

## そのほか、ChatGPTで使うときの注意

できた画像を `イラスト/<デッキ名>/<カード名>.png` に置いても、**`compose.ps1` は合成できない。**
同名の `.json` を読む作りのため。取り込みの仕組みは今は無いので、必要なら手で用意する。

## 注意事項

- **画像を生成しない。** 生成は `generating-card-art` の役目
- **mdを書き換えない。** プロンプトの中身を変えたいなら、元のmdを直すようユーザーに伝える
- **出力を要約しない。** プロンプトは丸ごと貼り付けて使うもの
- **`generating-card-art` を書き換えない。** 共有部分は `システム/` にあり、そちらを直すと両方に効く
