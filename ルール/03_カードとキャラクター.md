カードとキャラクター

## カードの種類

### キャラクターカード

場に出して戦う。表記は `コスト/攻撃力/HP`。

```
### まほうつかい 3枚（魔法使い）
2/2/3
召喚時：このターン中次に利用するスペルカードのコストを-1する
```

### スペルカード

使うと効果を発動し、そのまま墓地へ置かれる。表記は `Nコストスペル`。

```
### メラミ 3枚（魔法使い）
2コストスペル
３ダメージを与える
```

### リーダー

プレイヤー自身。HP25を持ち、クラスとテンションスキルを持つ。
**リーダーは場に含まれない**ため、「場のキャラクター」を対象にする効果は当たらない。
リーダーは武器を装備すると攻撃できる。

## カードに書く情報

| 項目 | 内容 |
|---|---|
| 名前 | カード名 |
| コスト | 使用に必要なMP |
| 攻撃力・HP | キャラクターのみ |
| 種族タグ | 冒険者 など。持たないカードもある |
| 効果 | キーワード能力と効果文 |

デッキとして書く際には職業とデッキに入れる枚数も記入する

## 召喚

キャラクターカードを使うと、自分の場に出る。これを**召喚**という。

- 自分の場は**6体**まで。埋まっているときは召喚できない
- 効果でキャラクターを出す場合も、空きが無ければ出ない。そのカードは元の場所（手札・デッキ・墓地）に留まる
- 「召喚時」の効果は、場に出た直後に発動する

## 召喚酔い

場に出たターン、そのキャラクターは攻撃できない。
突進を持つなら敵キャラクターを、速攻を持つなら敵キャラクターとリーダーを、そのターンから攻撃できる。

## ステータス

- **攻撃力**：戦闘で与えるダメージ量
- **HP**：受けられるダメージの残量。0以下になると破壊される
- **最大HP**：そのキャラクターのHPの上限

ダメージを受けてもターンをまたいで回復しない。ダメージは次のターンも残ったままになる。

### 増減

- `+X/+Y` は攻撃力を+X、**最大HPとHPを両方+Y**する
- 回復は最大HPを超えない
- ダメージは最大HPを減らさない
- 攻撃力は0未満にならない

## 場を離れる

キャラクターは、破壊・手札やデッキへの帰還などで場を離れる。
場を離れた時点で、そのキャラクターが与えていた継続効果は消える。
場を離れたキャラクターは、元の値・元の状態に戻った別個体として扱う。
