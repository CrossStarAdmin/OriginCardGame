# カードとキャラクター

## カードの種類

### キャラクターカード

場に出して戦う。HPが0以下になったら墓地へ置かれる。以下情報を持つ。

キャラクターをレストにすることで永続的にリーダーの攻撃力か防御力を+1することができる（強化）
ただし、その場合はそのキャラクターで攻撃できない
場に出たターンはレストにできない（召喚酔い）

| 項目 | 内容 |
|---|---|
| 名前 | カード名 |
| クラス | クラス名 |
| 種類 | キャラクター |
| コスト | 使用に必要なMP |
| 攻撃力 | そのカードの攻撃力 |
| 最大HP | そのカードのHP |
| 種族タグ | 冒険者 など。持たないカードもある |
| 効果 | キーワード能力と効果文 |

### スペルカード

使うと効果を発動し、そのまま墓地へ置かれる。以下情報を持つ。

| 項目 | 内容 |
|---|---|
| 名前 | カード名 |
| クラス | クラス名 |
| 種類 | スペル |
| コスト | 使用に必要なMP |
| 効果 | キーワード能力と効果文 |

### 武器カード

リーダー・キャラクターどちらも装備する。以下情報を持つ。

| 項目 | 内容 |
|---|---|
| 名前 | カード名 |
| クラス | クラス名 |
| 種類 | 武器 |
| コスト | 使用に必要なMP |
| 攻撃力 | 装備者の攻撃力に＋する値 |
| 効果 | キーワード能力と効果文 |

- 装備できる武器は装備者ごとに1つだけ。新しく装備すると、古い武器は破壊され墓地へ置かれる
- 装備者が場を離れると、武器も墓地へ置かれる
- 武器は場のキャラクター数に数えない

### ステージカード

場に永続的にあるカード。（一部カードで破壊可能）
以下情報を持つ

| 項目 | 内容 |
| ---- | --- |
| 名前 | カード名 |
| クラス | クラス名 |
| 種類 | ステージ |
| コスト | 出すのに必要なMP |
| 効果 | キーワード能力と効果分 |

### リーダー

プレイヤー自身。クラスとパワースキルを持つ。
パワースキルは3段階ある
また、リーダーはHPと攻撃力と防御力を持つ。ターン終了時にこれらの値を利用して相手リーダーにダメージを与える
**リーダーは場に含まれない**ため、「場のキャラクター」を対象にする効果は当たらない。

## 召喚

キャラクターカードを使うと、自分の場に出る。これを**召喚**という。

- 自分の場は**5体**まで。
- 場が埋まっている状態で手札や効果でキャラクターを出す場合、すでにある場のカードから１枚を墓地に送らないといけない。（その際死亡時効果も発動しない）
- 「召喚時」の効果は、**手札から使って場に出した直後にだけ**発動する。
- 「場に出たとき」の効果は、どの場所からであっても場に出た直後に発動する
- 場に出たターン、そのキャラクターは攻撃できない
- **突進**を持つなら敵キャラクターに攻撃することができる

## ステータス

- **攻撃力**：戦闘で与えるダメージ量
- **HP**：受けられるダメージの残量。0以下になると破壊される
- **最大HP**：そのキャラクターのHPの上限

ダメージを受けてもターンをまたいで回復しない。ダメージは回復しない限り残ったままになる。

### 増減

- `+X/+Y` は攻撃力を+X、**最大HPとHPを両方+Y**する
- 回復は最大HPを超えない
- ダメージは最大HPを減らさない
- 攻撃力は0未満にならない

## 破壊

- キャラクターは、HPが0以下になると破壊される
- 破壊されたキャラクターは、墓地に置かれる
- 破壊された場合、そのキャラが死亡時効果を持っていたらその効果を発動する。
- 破壊された時点で、そのキャラクターが与えていた継続効果は消える

## 消滅

- キャラクターは、消滅の効果で選ばれるとバトルから除外される
- 消滅したキャラクターは墓地に置かれず、そのゲーム中は戻らない。墓地を参照する効果（墓地から選ぶ・復活させる等）の対象にもならない
- 消滅した時点で、そのキャラクターが与えていた継続効果は消える
