## 基本数値

| 項目 | 値 |
|---|---|
| デッキ枚数 | 40枚ちょうど |
| 同名カード上限 | 3枚 |
| 初期手札 | 先攻5枚／後攻5枚 |
| 開始時テンション | 先攻0／後攻2 |
| リーダーHP | 25 |
| 最大MP | 1から開始、毎ターン+1、上限10 |
| 場の上限 | 各プレイヤー6体 |
| コスト上限 | 10 |
| 手札上限 | なし |
| テンション | 0〜3 |

## 設計方針

- **配置・レーンは無い。** ユニットは並ぶだけで、前列・後列・列ごとの対応関係を持たない
- そのため守護は**盤面全体**を守る。列単位の防御は存在しない
- **進化（シャドウバース）は採用しない。** ターンごとの切り返し役はテンションが担う
- **リーダーは場に含まれる。** 「全体」はリーダーとユニットの両方に当たる
- **リーダーは武器を装備して攻撃する**（ドラゴンクエストライバルズと同じ）

### 採用しない要素

- レアリティと構築制限（レジェンドは1枚まで、など）
- 持ち時間、投了
- ランダム効果の明文化（ランダム効果を持つカードを作らない）
