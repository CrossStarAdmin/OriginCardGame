用語集

| 用語 | 意味 |
|---|---|
| **リーダー** | プレイヤー自身。HP25。場に含まれる |
| **テンションスキル** | リーダー固有の効果。テンション3で使える |
| **場** | 敵味方すべてのユニットとリーダー |
| **自分の場** | 自分のユニットとリーダー。ユニットは6体まで |
| **ユニット** | 場に出て戦うカード。キャラクターと同義 |
| **スペル** | 使うと効果を発動し、墓地へ置かれるカード。スペルと同義 |
| **武器** | リーダーが装備するカード。攻撃力と耐久力を持つ |
| **耐久力** | 武器の残り攻撃回数。0になると武器は破壊される |
| **コスト** | カードを使うのに必要なMP |
| **MP** | そのターン中に使えるMPの残量 |
| **最大MP** | そのターンのMPの総量。毎ターン+1、上限10 |
| **テンション** | 0〜3のゲージ。1ターン1回、1MPで+1できる |
| **スーパーハイテンション** | テンションが3の状態 |
| **召喚** | ユニットカードを場に出すこと |
| **召喚酔い** | 場に出たターンは攻撃できないこと |
| **破壊** | HPが0以下、または効果によって墓地へ置かれること。死亡と同義 |
| **墓地** | 使用済みのスペルと破壊されたユニット・武器が置かれる場所 |
| **マリガン** | 対戦開始時に1回だけ行う手札の引き直し |
| **デッキ切れ** | デッキが0枚の状態で引こうとすること。引こうとした側が敗北する |
| **クラス** | カードとリーダーの所属。デッキにはリーダーのクラスと共通のみ入る |
| **共通** | どのクラスのデッキにも入れられるカード |
| **冒険者** | 種族タグの一つ。効果の参照先に使う |

## 表記ゆれの統一

| 使う | 使わない |
|---|---|
| 守護 | におうだち |
| 召喚時 | 登場時 |
| クラス | 職業 |
| ユニット | キャラクター |
| スペル | スペル（※スペルブーストは固有名なのでそのまま） |
| テンションスキル | リーダースキル |

既存のデッキファイルには統一前の表記が残っている。カードを直すときに合わせる。
