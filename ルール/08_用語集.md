# 用語集

| 用語 | 意味 |
|---|---|
| **リーダー** | プレイヤー自身。HP25、攻撃力、防御力を持つ。場に含まれない |
| **パワースキル（PS）** | リーダー固有の効果。パワー3で使える。3段階あり、リーダーを強化した回数で上がる。本文では「パワースキル」と書き、PSは略称 |
| **場** | 敵味方すべてのキャラクター（リーダーは含まない） |
| **自分の場** | 自分のキャラクター。5体まで |
| **キャラクター** | 場に出て戦うカード |
| **スペル** | 使うと効果を発動し、墓地へ置かれるカード |
| **武器** | リーダーまたはキャラクターが装備するカード。装備者の攻撃力に+する |
| **コスト** | カードを使うのに必要なMP |
| **MP** | そのターン中に使えるMPの残量 |
| **最大MP** | そのターンのMPの総量。毎ターン+1、上限10 |
| **パワー** | 0〜3のゲージ。1ターン1回、1MPで溜められる |
| **パワーリンク** | 自分のパワーが溜まったときに発動する効果 |
| **聖水** | 後攻が1つ持って始める資源。使うとMPが1回復する。1ターン1つまで |
| **マックスパワー** | パワーが3の状態 |
| **召喚** | キャラクターカードを場に出すこと |
| **召喚酔い** | 場に出たターンは攻撃できず、レストにもできない |
| **レスト** | キャラクターやステージを横向きにすること。攻撃か強化したときに行う。自分の開始フェイズにアクティブにする。動いたことを表現するのに利用する。 |
| **アクティブ** | キャラクターやステージを縦向きにすること。召喚時やターン開始時は基本的にアクティブで出す |
| **攻撃** | キャラクターがキャラクターにダメージを与えること。その後レストにする |
| **リーダー攻撃** | リーダーがリーダーにダメージを与えること |
| **リーダー強化** | キャラクターがリーダーの攻撃力か防御力を+1すること。その後レストにする |
| **破壊** | HPが0以下、または効果によって墓地へ置かれること。死亡と同義 |
| **消滅** | キャラクターをバトルから除外すること。墓地へは置かれず、墓地を参照する効果の対象にもならない |
| **墓地** | 使用済みのスペルと破壊されたキャラクター・武器が置かれる場所 |
| **捨てる** | 手札のカードを選んで墓地へ置くこと。使ったことにはならないので、召喚時やスペルの効果は発動しない |
| **マリガン** | 対戦開始時に1回だけ行う手札の引き直し |
| **デッキ切れ** | デッキが0枚の状態で引こうとすること。引こうとした側が敗北する |
| **クラス** | カードとリーダーの所属。デッキにはリーダーのクラスと共通のみ入る |
| **共通** | どのクラスのデッキにも入れられるカード |

## 表記ゆれの統一

| 使う | 使わない |
|---|---|
| 守護 | におうだち |
| 召喚時 | 登場時 |
| クラス | 職業 |
| キャラクター | ユニット |
| スペル | スペル（※スペルブーストは固有名なのでそのまま） |
| パワー | テンション |
| パワースキル | テンションスキル、リーダースキル |
| パワーリンク | テンションリンク |
| マックスパワー | スーパーハイテンション |
| パワーを溜める | テンションを上げる |

既存のデッキファイルには統一前の表記が残っている。カードを直すときに合わせる。
