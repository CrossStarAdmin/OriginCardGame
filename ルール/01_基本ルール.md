# 基本ルール

## ゲームの目的

2人対戦。自分のリーダーを守りながら、相手リーダーのHPを0にする。

## 勝敗

次のいずれかを満たしたプレイヤーは**敗北**する。

- リーダーのHPが0以下になった
- 自分のデッキが0枚の状態でカードを引こうとした

両者が同時に敗北条件を満たした場合は**引き分け**。

## デッキ構築

- **40枚ちょうど**。
- 同名カードは**3枚まで**
- 使えるのは「リーダーのクラスのカード」と「共通のカード」のみ
- リーダーを1人選ぶ。リーダーはクラスとテンションスキルを持つ

## 対戦の準備

1. デッキをシャッフルする
2. 先攻・後攻をじゃんけん等で決める
3. お互いに５枚デッキから引く
4. マリガンを1回行う
5. 後攻はテンション2の状態で始める
6. 両者のリーダーHPを25、最大MPを0にする（1ターン目の開始時に1へ増える）

## マリガン

引いた手札から任意の枚数を選び、裏向きでデッキの下に戻す。戻した枚数と同じ枚数を引く。
**引き終えてからデッキをシャッフルする**

マリガンは1回だけ。先攻・後攻の両方が行う。

## 先攻・後攻

| | 先攻 | 後攻 |
|---|---|---|
| 初期手札 | 5枚 | 5枚 |
| 開始時テンション | 0 | 2 |
| 1ターン目のドロー | なし | あり |

先攻は1ターン目のドローを行わない。後攻は1ターン目のドローとテンション2で補正する。
