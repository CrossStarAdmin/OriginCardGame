# 基本ルール

## ゲームの目的

2人対戦。リーダーVSリーダーのタイマンバトル。
自分のキャラクターカード等でリーダーカードを強化していきながら、相手のリーダーに攻撃する。相手のリーダーを先にHP0にしたら勝ち

## 勝敗

次のいずれかを満たしたプレイヤーは**敗北**する。

- リーダーのHPが0以下になった
- 自分のデッキが0枚の状態でカードを引こうとした

両者が同時に敗北条件を満たした場合は**引き分け**。

## デッキ構築

- **40枚ちょうど**。
- 同名カードは**3枚まで**
- 使えるのは「リーダーのクラスのカード」と「共通のカード」のみ
- リーダーを1人選ぶ。リーダーはクラスとパワースキル（3段階）と攻撃力と防御力を持つ

## 対戦の準備

1. デッキをシャッフルする
2. 先攻・後攻をじゃんけん等で決める
3. お互いに5枚デッキから引く
4. マリガンを1回行う
5. 後攻はパワー2、聖水1つの状態で始める
6. 両者のリーダーの最大MPを0にする（1ターン目の開始時に1へ増える）

## マリガン

引いた手札から任意の枚数を選び、裏向きでデッキの下に戻す。戻した枚数と同じ枚数を引く。
**引き終えてからデッキをシャッフルする**

マリガンは1回だけ。先攻・後攻の両方が行う。先攻からマリガンを行う。

## 先攻・後攻

| | 先攻 | 後攻 |
|---|---|---|
| 初期手札 | 5枚 | 5枚 |
| 開始時パワー | 0 | 2 |
| 1ターン目のドロー | なし | あり |
| 1ターン目のリーダーの攻撃 | なし | あり |
| 聖水 | なし | 1つ |

先攻は1ターン目のドローとリーダーの攻撃を行わない。後攻は1ターン目のドローとリーダーの攻撃、パワー2、聖水1つで補正する。

## リーダーの攻撃

- リーダーはターン終了時に相手リーダーに自動で攻撃する
- ダメージは次の順で決まる

1. 「味方リーダーの攻撃力 − 相手リーダーの防御力」を求める
2. 結果が0未満なら、0にする（防御力が攻撃力以上ならダメージは通らない）
3. カードの効果によるダメージの増減を適用する

## 聖水

後攻だけが持つ、手番の遅れを埋めるための資源。

- 後攻は**聖水を1つ**持って対戦を始める
- 自分のメインフェイズに聖水を1つ使うと、**MPが1回復する**
- 使えるのは**1ターンに1つまで**
- 使わなかった聖水はターンをまたいで持ち越される

聖水は最大MPを変えない。MPが最大MPと同じときに使うと、そのターンだけ最大MPを超える。
