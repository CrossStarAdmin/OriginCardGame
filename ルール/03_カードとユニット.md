カードとユニット

## カードの種類

### ユニットカード

場に出して戦う。表記は `コスト/攻撃力/HP`。

```
### まほうつかい 3枚（魔法使い）
2/2/3
召喚時：このターン中次に利用するスペルカードのコストを-1する
```

### スペルカード

使うと効果を発動し、そのまま墓地へ置かれる。表記は `Nコストスペル`。

```
### メラミ 3枚（魔法使い）
2コストスペル
３ダメージを与える
```

### 武器カード

リーダーが装備する。表記は `Nコスト武器` と `攻撃力/耐久力`。

```
### 鉄の斧 2枚（戦士）
3コスト武器
3/2
```

- 装備しているあいだ、リーダーは攻撃できる（[04_戦闘.md](04_戦闘.md)）
- 装備できる武器は1つだけ。新しく装備すると、古い武器は破壊され墓地へ置かれる
- 武器は場のユニット数に数えない

### リーダー

プレイヤー自身。HP25を持ち、クラスとテンションスキルを持つ。
リーダーも**場に含まれる**。ユニットだけを対象にしたい効果は「ユニット」と書く。

## カードに書く情報

| 項目 | 内容 |
|---|---|
| 名前 | カード名 |
| コスト | 使用に必要なMP |
| 攻撃力・HP | ユニットのみ |
| 攻撃力・耐久力 | 武器のみ |
| 種族タグ | 冒険者 など。持たないカードもある |
| 効果 | キーワード能力と効果文 |

デッキとして書く際にはクラスとデッキに入れる枚数も記入する

## 召喚

ユニットカードを使うと、自分の場に出る。これを**召喚**という。

- 自分の場に出せるユニットは**6体**まで。埋まっているときは召喚できない
- 効果でユニットを出す場合も、空きが無ければ出ない。そのカードは元の場所（手札・デッキ・墓地）に留まる
- 「召喚時」の効果は、場に出た直後に発動する

## 召喚酔い

場に出たターン、そのユニットは攻撃できない。
突進を持つなら敵ユニットを、速攻を持つなら敵ユニットとリーダーを、そのターンから攻撃できる。
リーダーには召喚酔いが無く、武器を装備したターンから攻撃できる。

## ステータス

- **攻撃力**：戦闘で与えるダメージ量
- **HP**：受けられるダメージの残量。0以下になると破壊される
- **最大HP**：そのユニットのHPの上限

ダメージを受けてもターンをまたいで回復しない。ダメージは次のターンも残ったままになる。

### 増減

- `+X/+Y` は攻撃力を+X、**最大HPとHPを両方+Y**する
- 回復は最大HPを超えない
- ダメージは最大HPを減らさない
- 攻撃力は0未満にならない

## 場を離れる

ユニットは、破壊・手札やデッキへの帰還などで場を離れる。
場を離れた時点で、そのユニットが与えていた継続効果は消える。
場を離れたユニットは、元の値・元の状態に戻った別個体として扱う。
