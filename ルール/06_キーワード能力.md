キーワード能力

全デッキ共通のキーワード。デッキ固有のものは各デッキファイルの「用語」節を正とする。

## 常在

| 名称 | 効果 |
|---|---|
| **守護** | 相手はこのユニットを先に攻撃しなければならない |
| **突進** | 出したターンから敵ユニットを攻撃できる |
| **速攻** | 出したターンから敵ユニット・リーダーを攻撃できる |
| **必殺** | 戦闘でダメージを与えたユニットを破壊する |
| **貫通** | 敵ユニットを攻撃して破壊したとき、余ったダメージを敵リーダーに与える |
| **超貫通** | ユニットに与えたダメージと同等のダメージ量をリーダーに与える |

## 誘発

| 名称 | 発動タイミング |
|---|---|
| **召喚時** | 場に出た直後 |
| **死亡時** | 破壊されて墓地へ置かれた直後 |
| **ターン開始時** | 自分の開始フェイズ |
| **ターン終了時** | 自分の終了フェイズ |
| **テンションリンク** | 自分のテンションが上がったとき |
| **おうえん** | 召喚時にテンションを+1する |

## 状態

| 名称 | 効果 |
|---|---|
| **封印** | 持っている能力をすべて失う。攻撃はできる。破壊はされない。場を離れるまで続く |
| **動けない** | そのユニットは攻撃できない。効果は発動する |

## デッキ固有キーワード

以下は特定デッキの仕組み。採用しているデッキのファイルに定義を書く。

| 名称 | デッキ | 内容 |
|---|---|---|
| **スペルブースト** | アグロゼシカ | 墓地のスペルの数だけ後続の効果を発動する |
| **ルック** | ミッドレンジ奇数ミネア | デッキの上1枚を見る。条件に合えば後続の効果を発動する |
| **残火** | アグロリーゼ | このターンに自分がスペルを使っていたなら後続の効果を発動する |

## 記法

- 「敵全体」「味方全体」は**リーダー**と**ユニット**どちらも含める
- 「場」は敵味方すべてのリーダーとユニット。
- ユニットやリーダーを特定したい場合は「敵ユニット」や「味方リーダー」という言い方をする
- 「1体」は対象を選ぶ。「全体」は選ばない
- 対象が書かれていない効果は、**敵味方すべて**（リーダーとユニットの両方）が対象になる
