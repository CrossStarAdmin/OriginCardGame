# キーワード能力

全デッキ共通のキーワード。デッキ固有のものは各デッキファイルの「用語」節を正とする。

## 常在

| 名称 | 効果 |
|---|---|
| **守護** | 相手はこのキャラクターを先に攻撃しなければならない |
| **突進** | 出したターンから敵キャラクターを攻撃できる |
| **速攻** | 出したターンから敵キャラクター・リーダーを攻撃できる |
| **必殺** | 戦闘でダメージを与えたキャラクターを破壊する |
| **貫通** | キャラクターを攻撃したとき、そのキャラクターの残りHPを超えたぶんのダメージをリーダーに与える |

## 誘発

| 名称 | 発動タイミング |
|---|---|
| **召喚時** | 場に出た直後 |
| **死亡時** | 破壊されて墓地へ置かれた直後 |
| **ターン開始時** | 自分の開始フェイズ |
| **ターン終了時** | 自分の終了フェイズ |
| **テンションリンク** | 自分のテンションが上がったとき |
| **おうえん** | 召喚時にテンションを+1する |

## 状態

| 名称 | 効果 |
|---|---|
| **封印** | 持っている能力をすべて失う。攻撃はできる。破壊はされない。破壊・消滅するまで続く |
| **動けない** | そのキャラクターは攻撃できない。効果は発動する |
| **消滅** | このキャラクターをバトルから除外する。墓地へは置かれず、墓地を参照する効果の対象にもならない |

## デッキ固有キーワード

以下は特定デッキの仕組み。採用しているデッキのファイルに定義を書く。

| 名称 | デッキ | 内容 |
|---|---|---|
| **残火** | アグロリーゼ | このターンに自分がスペルを使っていたなら後続の効果を発動する |
| **ルック** | ミッドレンジ奇数エルナ | デッキの上1枚を見る。条件に合えば後続の効果を発動する |
| **消耗** | コントロールアルベル | 相手の手札が2枚以下なら後続の効果を発動する（現状は参照カード未実装） |
| **解放** | ランプヴァルカス | 自分の最大MPが8以上なら後続の効果を発動する |
| **全解放** | ランプヴァルカス | 自分の最大MPが10なら後続の効果を発動する |

## 記法

- 「敵全体」「味方全体」は**リーダー**と**キャラクター**どちらも含める
- 「場」は敵味方すべてのキャラクター（リーダーを含まない）
- 「全体」は敵味方すべてのリーダーとキャラクター
- キャラクターやリーダーを特定したい場合は「敵キャラクター」や「味方リーダー」という言い方をする
- 「1体」は対象を選ぶ。「全体」は選ばない
- 対象が書かれていない効果は、**敵味方のリーダーとキャラクターすべて**の中から1体を選んで対象にする
